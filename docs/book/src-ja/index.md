## 本書の概要

Lean、Coq、Agda といった対話的定理証明器の中心には、項が与えられた型を持つかどうかを判定する小さな*カーネル*（kernel）があります。タクティクや記法、自動化といったほかの部分は、どれもカーネルに検査させる項を作るための足場にすぎません。そのためカーネルさえ正しければ、ほかの部分にバグがあっても、定理の証明に失敗することはあれ、偽の定理が受理されることはありません。

MiniLean4 は、Lean 4、Coq、Agda と同じ依存型理論に基づく小さな証明カーネルです。項の表現から証明の検査まで、Rust のコードを順に追っていきます。そうすると、定理証明器のどこを信頼しなければならないのか、Curry-Howard 対応が実際の検査器でどう働くのかが見えてきます。

本書では、カーネルの仕組みを具体的に解説します。各章では一つの概念を取り上げ、正確に定式化したうえで、それを実装する Rust のコードを紹介します。カーネル、タクティク、パーサを合わせても実装は三千行に満たず、外部ライブラリにも依存していません。

前提知識としては、再帰関数と簡単な集合の記法が読めれば十分です。型理論や Lean の予備知識は必要ありませんが、Lean を知っている人には見覚えのある話も多いでしょう。

**第 I 部**では依存型理論の型検査器を作り、この型検査器がそのまま、ある論理の証明検査器として働くことを確かめます。**第 II 部**では帰納型（自然数、木、リスト、ベクトル、等式）と、証明項を組み立ててくれるタクティク言語を加えます。**第 III 部**では、第 I 部と第 II 部で深入りしなかった代入、α 同値、簡約の中身に踏み込みます。カーネルのバグが潜みやすいのはこの部分です。**第 IV 部**では宇宙の階層がなぜこの形をしているのかを説明し、メタ理論を述べます。付録には、完全な証明、宇宙の設計の背景にあるパラドックス、スクリプト言語のリファレンスを収めました。

本書には、4 種類の対話的な要素が登場します。

- **プレイグラウンド**ではカーネルを実際に動かせます。スクリプトを編集して実行ボタンを押し、出力を確かめてください。
- **エクスプローラ**は、カーネル自身が項をどう見ているかを表示します。構文木、規則ごとの型付け導出、一歩ずつの簡約、各変数がどの束縛子に属するか、タクティクを適用するたびの証明状態などです。どのエクスプローラもライブで動き、項を書き換えるとカーネルがその場で計算し直します。
- **ステッパー**はアルゴリズムを一歩ずつ進め、各ステップの後の状態を表示します。
- **呼び出し木**は、型検査器がある項に対して行う再帰呼び出しを実際の順序どおりに並べ、それぞれに対応する型付け規則を添えて表示します。

「コードでは」と記したコラムは、直前に定義した内容を実装している Rust の関数を示します。演習には解答が付いており、開くまでは折りたたまれています。

## 自分でコードを動かしてみよう！

リポジトリには、カーネルとコマンドラインの実行器、そして本書で使う例題スクリプトが入っています。

```text
cargo run -- examples/identity.leanmini
cargo run -- examples/nat-reflexivity.leanmini
cargo run -- examples/zero-add.leanmini
cargo run -- examples/generic-list.leanmini
cargo run -- examples/generic-vec.leanmini
cargo test
```

`cargo run` を引数なしで実行すると対話セッションが始まり、同じコマンドを一行ずつ入力できます。言語の詳細は[付録 E](e-leanmini-reference.md) で説明します。

ソースコードは本書の流れに沿って構成されています。

| ファイル | 内容 | 章 |
|---|---|---|
| `src/term.rs` | 項の表現 | 2 |
| `src/typecheck.rs` | 型推論と型検査 | 5, 6 |
| `src/substitution.rs` | 自由変数、代入、α 同値 | 11 |
| `src/reduction.rs` | 弱頭正規形、正規化、定義的等価 | 12 |
| `src/declaration.rs` | シグネチャ: 定数、定義、帰納型のメタデータ | 7, 8 |
| `src/inductive/` | 帰納的宣言の検査と再帰子の生成 | 8 |
| `src/proof.rs` | ゴール、証明状態、タクティク | 10 |
| `src/syntax.rs` | スクリプト言語のパーサ | 付録 E |
| `src/main.rs` | コマンドラインの実行器 | 付録 E |

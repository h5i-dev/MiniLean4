第 9 章

等式も帰納型である

0+n=n0 + n = n0+n=n のような数に関する事実を述べるには、等しさを表す手段が要る。専用の規則がカーネルに組み込まれているように思えるかもしれないが、等式も第 8 章の手順で生成される帰納型の一つであり、その再帰子を使えば、aaa についての事実を bbb についての事実へ移せる。本章ではこの型を宣言し、定義的等価との違いを説明してから、本書で最初の本格的な定理を証明する。

宣言

Lean では、等式は次のように宣言されている。

inductive Eq {A : Sort u} (a : A) : A -> Prop where
  | refl : Eq a a

a,b:Aa, b : Aa,b:A に対して、型 Equ  A  a  b\Eq{u}\;A\;a\;bEqu​Aab は aaa と bbb が等しいという命題である。AAA が Nat\NatNat のときは a=ba = ba=b と書く。第 8 章の言葉でいえば、AAA と aaa がパラメータで bbb が添字である。

Equ:Π(A:Sort u). A→A→Sort 0,reflu:Π(A:Sort u). Π(a:A). Equ  A  a  a.\Eq{u} : \tPi{A}{\Sort{u}}{A \to A \to \Sort{0}}, \qquad \refl{u} : \tPi{A}{\Sort{u}}{\tPi{a}{A}{\Eq{u}\;A\;a\;a}}.Equ​:Π(A:Sortu).A→A→Sort0,reflu​:Π(A:Sortu).Π(a:A).Equ​Aaa.

唯一の構成子 reflu\refl{u}reflu​ はフィールドを持たず、その添字項は aaa なので、両辺が同じ aaa である等式しか証明できない。したがって Eq\Eq{}Eq​ は単一の型ではなく Vec\mathsf{Vec}Vec と同じ帰納族であり、左辺はパラメータで固定され、右辺は変化するが、構成子がそれを左辺に釘付けにする。

なぜ構成子が一つで足りるのか。この宣言は、二つのものがいつ等しいかを定義しているのではなく、等式の証明がどう組み立てられるかを述べているのであり、その唯一の方法が「あるものはそれ自身に等しい」と認めることである。対称性、推移性、代入といった残りはすべて再帰子から導かれ、再帰子はそうした証明を手にしたとき何ができるかを述べる。

再帰子: 輸送

くだけて言えば、Eq\Eq{}Eq​ の再帰子はこう述べている。a=ba = ba=b ならば、aaa について成り立つことは何であれ bbb についても成り立つ。 これはライプニッツの原理であり、最もよく使われる形では次のように読める。

Eq.ndrecu,v:Π(A:Sort u). Π(a:A). Π(M:A→Sort v). M  a→Π(b:A). Equ  A  a  b→M  b.\EqRec{u,v} : \tPi{A}{\Sort{u}}{\tPi{a}{A}{\tPi{M}{A \to \Sort{v}}{M\;a \to \tPi{b}{A}{\Eq{u}\;A\;a\;b \to M\;b}}}}.Eq.ndrecu,v​:Π(A:Sortu).Π(a:A).Π(M:A→Sortv).Ma→Π(b:A).Equ​Aab→Mb.

AAA の要素についての性質 MMM、証拠 m:M  am : M\;am:Ma、そして a=ba = ba=b の証明 hhh が与えられると、M  bM\;bMb の証拠を返す。mmm を hhh に沿って輸送（transport）する、という。その計算規則は、refl\refl{}refl​ に沿った輸送は何もしない、というものである。

Eq.ndrecu,v  A  a  M  m  b  (reflu  A  c)  →  m.\EqRec{u,v}\;A\;a\;M\;m\;b\;(\refl{u}\;A\;c) \;\to\; m.Eq.ndrecu,v​AaMmb(reflu​Ac)→m.

第 8 章の一般的な手順が生成するものはこれより少し一般的で、Eq.ndrec\EqRec{}Eq.ndrec​ はそれから組み立てた定義である。

Lean では Eq の型引数は暗黙で、宣言では {A} と書き、エラボレータが補う。そのためユーザーは Eq a b や a = b と書けるが、本書のカーネルが扱う項は完全に明示的であり、引数をすべて書く必要がある。引数の補完はカーネルより上の層の仕事である。スクリプト言語には Eq と Eq.refl、依存再帰子 Eq.rec0 と Eq.rec1 がある。非依存の Eq.ndrec\EqRec{}Eq.ndrec​ はあらかじめ宣言されていないが、下のプレイグラウンドに示すように二行で定義できる。また、宇宙多相がないため、カーネルは Eq を A:Sort 1A : \Sort{1}A:Sort1 で一度だけ宣言し、これで Nat\NatNat とユーザーが宣言するすべてのデータ型を扱えるが、証明どうしの等式は使えない。

定義的等価と命題的等価

いまや等しさの概念が二つあり、この二つを区別することが、証明支援系の振る舞いを理解するうえで欠かせない。

  • 定義的等価 ≡\conv≡ は、カーネルが計算によって決定する。項についての判断であって型ではなく、証明オブジェクトは関与しない。
  • 命題的等価 Eq\Eq{}Eq​ は型であり、その証明は項で、見つけるには帰納法のような本物の推論が要ることがある。

構成子 refl\refl{}refl​ が両者をつなぐ。T-Conv により、a≡ba \conv ba≡b であれば常に reflu  A  a:Equ  A  a  b\refl{u}\;A\;a : \Eq{u}\;A\;a\;breflu​Aa:Equ​Aab となるので、定義的等価からは命題的等価がただで得られるが、逆は成り立たない。標準的な例が n+0=nn + 0 = nn+0=n と 0+n=n0 + n = n0+n=n の二つである。第 7 章の add\addadd の定義を使い、その段階関数を sss とすると、

命題論理から等式付きの算術に進むのに、変更はわずかで済んだ。Infer\InferInfer には定数のケースが加わって Σ\SigmaΣ から型を引く（T-Const）一方、Check\CheckCheck は変わらない。新しい δ ステップと ι ステップを覚えたのは Whnf\WhnfWhnf だけで、それを通して IsDefEq\IsDefEqIsDefEq も変わった。第 12 章では一つの Whnf\WhnfWhnf がすべての帰納型を扱う仕組みを示し、第 14 章では帰納型がメタ理論にもたらす変化を論じる。

Eq\Eq{}Eq​ は命題であるのにすべての宇宙へ消去できる一方、構成子が二つある型 Or はそうではない。理由を説明せよ。

解答

Eq\Eq{}Eq​ は部分単集合であり、構成子は一つで、フィールドはない。そのような証明の組み立て方が一通りしかないので、その再帰子で定義した関数は a=ba = ba=b の二つの証明を区別できない。Or には構成子が二つあるので、Nat\NatNat への再帰子は二つの注入に対して異なる数を返せてしまい、プログラムの値がどちらの証明が与えられたかに依存することになる。第 8 章にこの規則の正確な形がある。

覚えておくこと

  • Eq\Eq{}Eq​ は、パラメータ AAA と aaa、添字 bbb、フィールドを持たない唯一の構成子 refl\refl{}refl​ からなる帰納族である。
  • その再帰子は、a=ba = ba=b の証明に沿って aaa についての事実を bbb についての事実へ輸送し、refl\refl{}refl​ に対しては何もしない。これが書き換えである。
  • 定義的等価は計算で決定される一方、命題的等価は型であり、その証明には帰納法が要ることがある。refl\refl{}refl​ が前者を後者に変える。
  • 加法が第二引数で再帰するので、n+0=nn + 0 = nn+0=n は定義的で 0+n=n0 + n = n0+n=n はそうでない。

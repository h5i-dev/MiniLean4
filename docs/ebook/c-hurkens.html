Appendix C

Hurkens' Paradox

Chapter 13 claimed that a single universe containing itself makes the type theory inconsistent: there is a closed term of type Π(p:Type). p\tPi{p}{\mathsf{Type}}{p}Π(p:Type).p, a proof of everything. This appendix gives that term in full, explains the idea behind it, and shows exactly where the rule Type:Type\mathsf{Type} : \mathsf{Type}Type:Type is used, so that you can see why the universe hierarchy blocks it.

The setting

Throughout this appendix the universes of the kernel are replaced by one universe Type\mathsf{Type}Type with the two rules

⊢Γ;okΓ⊢Type:TypeΓ⊢A:TypeΓ,x:A⊢B:TypeΓ⊢Π(x:A). B:Type\dfrac{\ctxok{\Gamma}}{\Gamma \vdash \mathsf{Type} : \mathsf{Type}} \qquad \dfrac{\Gamma \vdash A : \mathsf{Type} \qquad \Gamma, x : A \vdash B : \mathsf{Type}}{\Gamma \vdash \tPi{x}{A}{B} : \mathsf{Type}}Γ⊢Type:Type⊢Γ;ok​Γ⊢Π(x:A).B:TypeΓ⊢A:TypeΓ,x:A⊢B:Type​

in place of T-Sort and T-Pi. Everything else, including T-Lam, T-App, T-Conv, substitution, and β\betaβ-reduction, is unchanged. The goal is a closed term tHt_{\mathrm{H}}tH​ with

⊢tH:⊥,⊥=Π(p:Type). p.\vdash t_{\mathrm{H}} : \bot, \qquad \bot = \tPi{p}{\mathsf{Type}}{p}.⊢tH​:⊥,⊥=Π(p:Type).p.

Such a term proves every proposition CCC, because tH  C:Ct_{\mathrm{H}}\;C : CtH​C:C.

The construction is due to Girard, who adapted the Burali-Forti paradox of set theory to the type theory with Type:Type\mathsf{Type} : \mathsf{Type}Type:Type [Girard 1972]. The term below is Hurkens' simplification [Hurkens 1995], which fits on one page and uses nothing beyond Π\PiΠ, λ\lambdaλ, and application.

Power sets in type theory

Read a function p:S→Typep : S \to \mathsf{Type}p:S→Type as a predicate on SSS, or equivalently as a subset of SSS: the elements xxx for which p  xp\;xpx has a proof are the members. The type of all such predicates is the power set of SSS:

℘S  =  S→Type.\wp S \;=\; S \to \mathsf{Type}.℘S=S→Type.

Applying this twice, ℘℘S=(S→Type)→Type\wp\wp S = (S \to \mathsf{Type}) \to \mathsf{Type}℘℘S=(S→Type)→Type is the type of families of subsets of SSS.

In set theory, Cantor's theorem says that no set contains a copy of its own power set, let alone of its double power set: ℘S\wp S℘S is always strictly larger than SSS. The paradox is built on a type UUU that violates this. It contains a copy of ℘℘U\wp\wp U℘℘U, with a function τ:℘℘U→U\tau : \wp\wp U \to Uτ:℘℘U→U that packs a family of subsets of UUU into a single element of UUU, and a function σ:U→℘℘U\sigma : U \to \wp\wp Uσ:U→℘℘U that unpacks it again. The type

U  =  Π(X:Type). ((℘℘X→X)→℘℘X)U \;=\; \tPi{X}{\mathsf{Type}}{\bigl((\wp\wp X \to X) \to \wp\wp X\bigr)}U=Π(X:Type).((℘℘X→X)→℘℘X)

achieves this by quantifying over all of Type\mathsf{Type}Type. For UUU to be a member of Type\mathsf{Type}Type while quantifying over Type\mathsf{Type}Type is exactly what Type:Type\mathsf{Type} : \mathsf{Type}Type:Type permits and the hierarchy of Chapter 13 forbids.

How the term works

Packing and unpacking. The two functions τ:℘℘U→U\tau : \wp\wp U \to Uτ:℘℘U→U and σ:U→℘℘U\sigma : U \to \wp\wp Uσ:U→℘℘U are inverse enough for the argument. Unfolding the definitions and β\betaβ-reducing gives, for every t:℘℘Ut : \wp\wp Ut:℘℘U and p:℘Up : \wp Up:℘U,

σ  (τ  t)  p  ≡  t  (λ(x:U). p  (τ  (σ  x))).\sigma\;(\tau\;t)\;p \;\conv\; t\;(\tLam{x}{U}{p\;(\tau\;(\sigma\;x))}).σ(τt)p≡t(λ(x:U).p(τ(σx))).

This equation is used by the kernel through T-Conv at several points in tHt_{\mathrm{H}}tH​; it is a computation, not an axiom.

An ordering on UUU. Read σ  x  p\sigma\;x\;pσxp as "the predicate ppp holds of everything below xxx". This gives UUU something like an order, and lets us say two things about predicates and elements.

  • A predicate p:℘Up : \wp Up:℘U is inductive if whenever it holds of everything below xxx, it holds of xxx: that is, Π(x:U). σ  x  p→p  x\tPi{x}{U}{\sigma\;x\;p \to p\;x}Π(x:U).σxp→px.
  • An element x:Ux : Ux:U is well-founded if every inductive predicate holds of xxx: that is, Π(p:℘U). (Π(x:U). σ  x  p→p  x)→p  x\tPi{p}{\wp U}{(\tPi{x}{U}{\sigma\;x\;p \to p\;x}) \to p\;x}Π(p:℘U).(Π(x:U).σxp→px)→px.

The element Ω\OmegaΩ is built to play the part of "the collection of all well-founded elements": it packs the family consisting of all inductive predicates. In Burali-Forti's paradox this is the set of all ordinals, which is itself an ordinal, hence a member of itself, hence not well-founded although all ordinals are.

The three ingredients. Reading tHt_{\mathrm{H}}tH​ from the bottom up:

  1. The last line, λ(p:℘U). λ(h1:⋯ ). h1  Ω  (λ(x:U). h1  (τ  (σ  x)))\tLam{p}{\wp U}{\tLam{h_1}{\cdots}{h_1\;\Omega\;(\tLam{x}{U}{h_1\;(\tau\;(\sigma\;x))})}}λ(p:℘U).λ(h1​:⋯).h1​Ω(λ(x:U).h1​(τ(σx))), proves that Ω\OmegaΩ is well-founded. Its type is Π(p:℘U). (Π(x:U). σ  x  p→p  x)→p  Ω\tPi{p}{\wp U}{(\tPi{x}{U}{\sigma\;x\;p \to p\;x}) \to p\;\Omega}Π(p:℘U).(Π(x:U).σxp→px)→pΩ, which is the type of h0h_0h0​. So h0h_0h0​ stands for "Ω\OmegaΩ is well-founded".
  2. The predicate Δ  y\Delta\;yΔy says "yyy is not below itself" (strictly, it speaks of τ  (σ  y)\tau\;(\sigma\;y)τ(σy), which behaves like yyy by the equation above). The second argument of h0h_0h0​, the long λ\lambdaλ beginning λ(x:U). λ(h2:⋯ ). ⋯\tLam{x}{U}{\tLam{h_2}{\cdots}{\cdots}}λ(x:U).λ(h2​:⋯).⋯, proves that Δ\DeltaΔ is inductive. Since Δ  Ω\Delta\;\OmegaΔΩ is the negation of "Ω\OmegaΩ is below itself", applying the result of step 2 to the result of step 3 yields a term of type ⊥\bot⊥.

The argument is Burali-Forti's in disguise. Ordinals are well-founded; the collection Ω\OmegaΩ of all ordinals is an ordinal, so it is a member of itself; but no well-founded thing is a member of itself. Set theory escapes by refusing to let the collection of all ordinals be a set. The type theory with Type:Type\mathsf{Type} : \mathsf{Type}Type:Type has no such refusal, because UUU can quantify over everything, including itself.

Where Type : Type is used

Every typing step in tHt_{\mathrm{H}}tH​ is ordinary except one. In σ=λ(s:U). s  U  τ\sigma = \tLam{s}{U}{s\;U\;\tau}σ=λ(s:U).sUτ, the variable s:Us : Us:U is applied to the type UUU itself. The type of sss begins Π(X:Type). ⋯\tPi{X}{\mathsf{Type}}{\cdots}Π(X:Type).⋯, so T-App requires U:TypeU : \mathsf{Type}U:Type. But UUU is a Π\PiΠ type that quantifies over Type\mathsf{Type}Type, and in a system with a universe hierarchy such a type lives one level above the universe it quantifies over:

Γ⊢Sort u:Sort (u+1)Γ,X:Sort u⊢B:Sort vΓ⊢Π(X:Sort u). B:Sort max⁡(u+1,v)\dfrac{\Gamma \vdash \Sort{u} : \Sort{(u+1)} \qquad \Gamma, X : \Sort{u} \vdash B : \Sort{v}}{\Gamma \vdash \tPi{X}{\Sort{u}}{B} : \Sort{\max(u+1, v)}}Γ⊢Π(X:Sortu).B:Sortmax(u+1,v)Γ⊢Sortu:Sort(u+1)Γ,X:Sortu⊢B:Sortv​

With the T-Pi rule of Chapter 13, UUU is in Sort (u+1)\Sort{(u+1)}Sort(u+1) at best, never in Sort u\Sort{u}Sortu, so s  Us\;UsU is ill typed and σ\sigmaσ cannot be written. The whole construction collapses at this one application. Impredicativity of Sort 0\Sort{0}Sort0 does not reopen the door: UUU has body (℘℘X→X)→℘℘X(\wp\wp X \to X) \to \wp\wp X(℘℘X→X)→℘℘X, whose result ℘℘X\wp\wp X℘℘X is a function type into a universe and therefore is not a proposition, so imax\mathrm{imax}imax does not place UUU in Sort 0\Sort{0}Sort0. Coquand showed that one impredicative universe at the bottom is consistent [Coquand 1988]; Hurkens' term shows that two impredicative levels are already too many [Hurkens 1995].

Reproducing it with the kernel

You can watch the kernel accept and reject this term. The only rule to change is T-Sort, implemented by the Term::Sort(u) case of infer in src/typecheck.rs:

// T-Sort, as shipped: every universe lives in the next one.
Term::Sort(u) => Ok(Term::Sort(u.checked_add(1).ok_or("universe overflow")?)),

Replace the right-hand side by Ok(Term::Sort(*u)), so that Sort 0:Sort 0\Sort{0} : \Sort{0}Sort0:Sort0, and use Sort 0\Sort{0}Sort0 as Type\mathsf{Type}Type throughout. Nothing else needs to change: with every type in Sort 0\Sort{0}Sort0, the T-Pi rule with imax\mathrm{imax}imax already assigns Sort 0\Sort{0}Sort0 to every Π\PiΠ type, which is the second rule of this appendix. With that one-line change, infer returns exactly Π(p:Sort 0). p\tPi{p}{\Sort{0}}{p}Π(p:Sort0).p for tHt_{\mathrm{H}}tH​. The unmodified kernel rejects the term with a type mismatch at the application s  Us\;UsU inside σ\sigmaσ, as predicted above.

Do not leave the modification in. Besides making the kernel inconsistent, it breaks termination: as Chapter 13 explains, tHt_{\mathrm{H}}tH​ has no normal form, so asking the modified kernel to normalize it runs until the reduction fuel of Chapter 12 is exhausted.

Why there is no normal form

Chapter 14 proves consistency of the real system by showing that no normal closed term has type Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P. The part of that proof that analyses the shapes of normal terms does not use strong normalization and goes through unchanged for Type:Type\mathsf{Type} : \mathsf{Type}Type:Type. So if tHt_{\mathrm{H}}tH​ had a normal form, that normal form would be a closed normal term of type ⊥\bot⊥, which cannot exist. Subject reduction still holds, so reduction cannot escape the type ⊥\bot⊥ either. The only remaining possibility is that tHt_{\mathrm{H}}tH​ reduces forever: strong normalization fails, and with it the termination of the type checker. Girard's paradox is therefore not only a logical defect but a computational one, and it is the reason the design of universes in Chapter 13 matters for the algorithm as much as for the logic.

What to remember

  • With Type:Type\mathsf{Type} : \mathsf{Type}Type:Type, the type UUU quantifies over all types while being one of them, so it contains a copy of its own double power set, which no set can do.
  • Hurkens' term tHt_{\mathrm{H}}tH​ turns this into Burali-Forti's paradox: Ω\OmegaΩ, the packed family of all inductive predicates, is both well-founded and below itself.
  • The rule Type:Type\mathsf{Type} : \mathsf{Type}Type:Type is used in exactly one place, the application s  Us\;UsU in σ\sigmaσ; a universe hierarchy makes that application ill typed.
  • The term has no normal form, so the paradox breaks termination of the kernel as well as consistency.

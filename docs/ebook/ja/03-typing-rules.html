第 3 章

型付け規則

カーネルの仕事は、判断「項 ttt は型 AAA を持つ」を判定することである。本章ではこの判断を少数の推論規則、すなわち項の種類ごとに一つと、型の内部で計算を許すための追加の一つで定義する。各規則を下から上へ読めば項を検査する手順になり、その手順が第 5 章のアルゴリズムになる。

文脈と判断

f  pf\;pfp のような項は単独では検査できず、その型は fff と ppp が何であるかに依存する。文脈（context）Γ\GammaΓ がその情報を記録する。文脈は仮定の順序付きリスト

Γ  =  x1:A1,  x2:A2,  …,  xn:An,\Gamma \;=\; x_1 : A_1,\; x_2 : A_2,\; \ldots,\; x_n : A_n,Γ=x1​:A1​,x2​:A2​,…,xn​:An​,

であり、スコープ内の各変数の型を与える。dom(Γ)\dom(\Gamma)dom(Γ) は名前の集合 {x1,…,xn}\{x_1, \ldots, x_n\}{x1​,…,xn​} を表し、空の文脈は ⋅\cdot⋅ と書く。

順序は重要であり、P:Sort 0,  h:PP : \Sort{0},\; h : PP:Sort0,h:P のように、後の型が前の変数に言及してよい。仮定 h:Ph : Ph:P は、PPP が命題だとわかってはじめて意味を持つ。文脈の中の名前は互いに異なることを要求するので、文脈は名前から型への辞書のように使えるが、その項目が順に互いへ依存する辞書である。

二つの判断を同時に定義する。

  • ⊢Γ;ok\ctxok{\Gamma}⊢Γ;ok は文脈 Γ\GammaΓ が整形式（well formed）であること、すなわち仮定された各型がその手前の文脈において型であることを意味する。
  • Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A は、Γ\GammaΓ の仮定のもとで項 ttt が型 AAA を持つことを意味する。

Curry-Howard の目で見れば、Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A は、ttt が仮定 Γ\GammaΓ からの AAA の証明であると言っている。

規則のうち二つは項に対する操作を使っているが、続く数章ではそれをブラックボックスとして扱う。

代入。 T-App は、BBB の中の xxx の自由な出現をすべて aaa で置き換えた結果を B[x↦a]\subst{B}{x}{a}B[x↦a] と書く。たとえば (P→P)[P↦Q]=Q→Q\subst{(P \to P)}{P}{Q} = Q \to Q(P→P)[P↦Q]=Q→Q である。束縛子の内側で名前を置き換えるには注意が要り、それは第 11 章で説明するが、それまでは直観的な意味で十分である。

定義的等価。 T-Conv は、AAA と BBB がカーネルに機械的に判定できる意味で「同じ型」であるとき、A≡BA \conv BA≡B と書く。二種類の違いが無視される。

  • 束縛変数の名前。Π(P:Sort 0). P→P\tPi{P}{\Sort{0}}{P \to P}Π(P:Sort0).P→P と Π(Q:Sort 0). Q→Q\tPi{Q}{\Sort{0}}{Q \to Q}Π(Q:Sort0).Q→Q は同じ命題を述べている。この点だけが異なる項を α 同値と呼び、A=αBA \alphaeq BA=α​B と書く。
  • 計算。Id=λ(X:Sort 0). X\mathit{Id} = \tLam{X}{\Sort{0}}{X}Id=λ(X:Sort0).X とすると、Id  P\mathit{Id}\;PIdP は XXX に PPP を代入して PPP に計算されるので、Id  P\mathit{Id}\;PIdP の証明は PPP の証明として数えられるべきである。計算の一歩 (λ(x:A). t)  s→βt[x↦s](\tLam{x}{A}{t})\;s \betared \subst{t}{x}{s}(λ(x:A).t)s→β​t[x↦s] を β 簡約（beta-reduction）と呼ぶ。

カーネルは A≡BA \conv BA≡B を、両辺を可能な限り計算してから結果が α 同値かどうかを調べることで判定する。第 12 章でこれを正確に定義する。

規則の読み方

規則は下から上へ、結論を立てるには前提を立てよという手順として読むのがよい。

C-Empty と C-Ext。 文脈は仮定を一つずつ加えて作り、新しい仮定の型はそれ自体が型でなければならない。側条件 x∉dom(Γ)x \notin \dom(\Gamma)x∈/dom(Γ) は同じ名前の仮定が二つあることを禁じるが、束縛変数の名前は重要でないので、これは何も制限していない。衝突しそうな束縛子は、先に名前を付け替えればよい。この条件を省いたカーネルで何が起きるかは第 11 章で示す。

T-Sort。 どの宇宙も次の宇宙に住み、Sort 0:Sort 1\Sort{0} : \Sort{1}Sort0:Sort1、Sort 1:Sort 2\Sort{1} : \Sort{2}Sort1:Sort2、以下同様である。宇宙が自分自身の型にはなれない理由は第 13 章で説明する。

T-Var。 変数は文脈が割り当てる型を持ち、論理的には仮定を使うことにあたる。

T-Pi。 AAA が型で、x:Ax : Ax:A を仮定したうえで BBB が型なら、Π(x:A). B\tPi{x}{A}{B}Π(x:A).B は型である。結果の宇宙は imax(u,v)\imax(u, v)imax(u,v) で、v=0v = 0v=0 なら 000、そうでなければ max⁡(u,v)\max(u, v)max(u,v) である。言葉にすると、Π\PiΠ 型は本体が命題でありさえすれば何の上で量化していようと命題であり、そうでなければ二つの宇宙の大きい方に住む。論理的には、この規則は A→BA \to BA→B と ∀x:A. B\forall x{:}A.\,B∀x:A.B がいつ整形式の主張であるかを言っている。

T-Lam。 AAA から BBB への関数を作るには、x:Ax : Ax:A を仮定して型 BBB の項 ttt を作る。本体の型 BBB は xxx に言及してよく、結果の Π\PiΠ 型にそのまま残る。依存性が入り込むのはここである。論理的には、これは含意と全称量化子の導入規則であり、A→BA \to BA→B を証明するには AAA を仮定して BBB を証明する。

T-App。 fff が各 x:Ax : Ax:A を BBB の要素に写し、a:Aa : Aa:A なら、f  af\;afa は BBB の xxx を aaa で置き換えた型を持つ。BBB が xxx に言及しないなら、これは A→BA \to BA→B と AAA から BBB を結論するモーダスポネンスであり、言及するなら全称命題の具体化である。たとえば f:Π(n:Nat). n+0=nf : \tPi{n}{\Nat}{n + 0 = n}f:Π(n:Nat).n+0=n なら f  3:3+0=3f\;3 : 3 + 0 = 3f3:3+0=3 である（自然数は第 7 章で登場する）。

T-Conv。 計算を除いて等しい型は交換可能であり、h:Id  Ph : \mathit{Id}\;Ph:IdP から h:Ph : Ph:P を結論してよい。前提 Γ⊢B:Sort u\Gamma \vdash B : \Sort{u}Γ⊢B:Sortu は、新しい型がそれ自体型であることを保証する。これは、使うかどうかが ttt の形から決まらない唯一の規則であり、この事実は第 5 章のアルゴリズムで効いてくる。

どの規則も、関数についての小さな常識である。T-Lam は関数の作り方、T-App は使い方、T-Pi は関数型がいつ意味を持つか、T-Var と T-Sort は基本的なものが何であるか、T-Conv は型の内部で計算しても意味は変わらないことを言う。規則の中にとくに「論理的」なものは何もなく、論理は規則を Curry-Howard を通して読んだ帰結であり、それを第 4 章で正確にする。

適用が重要な理由

何かを組み立てる T-Lam や T-Pi のほうが重要に見えるかもしれないが、T-App がなければ、証明は仮定を返せても使うことはできない。おおまかに言えば、証明できるのは P→Q→PP \to Q \to PP→Q→P のように、結論が仮定の一つそのものである命題だけになる。合成

(P→Q)→(Q→R)→P→R,(P \to Q) \to (Q \to R) \to P \to R,(P→Q)→(Q→R)→P→R,

の証明は λ(f:P→Q). λ(g:Q→R). λ(p:P). g (f p)\tLam{f}{P \to Q}{\tLam{g}{Q \to R}{\tLam{p}{P}{g\,(f\,p)}}}λ(f:P→Q).λ(g:Q→R).λ(p:P).g(fp) で、fff を適用してから ggg を適用する。仮定を言い直す以上のことをする証明はすべて T-App を通る。そして依存型理論では、T-App は代入が起きる場所でもあり、したがって微妙な点の大半が潜む場所でもある。

カーネルが組み立てるのはこの木であり、下の表示では各節点が規則の一回の適用で、それが立証する判断を伴う。呼び出しビューに切り替えると、この木を生み出す再帰として上から下へ読める。項を自分のものに置き換えて、どの規則が発火するか見てみてほしい。

二つ観察しておく。第一に、木の形は項の形に従い、根に λ\lambdaλ、その下に λ\lambdaλ、葉に変数である。第二に、根の型は Π(P:Sort 0). Π(h:P). P\tPi{P}{\Sort{0}}{\tPi{h}{P}{P}}Π(P:Sort0).Π(h:P).P だが、述べた命題は Π(P:Sort 0). P→P\tPi{P}{\Sort{0}}{P \to P}Π(P:Sort0).P→P だった。両者は束縛変数の名前（hhh か、矢印の無名の _ か）だけが異なるので α 同値であり、T-Conv がその隙間を埋める。第 6 章でこの例をアルゴリズムで再訪する。

本章の規則は src/typecheck.rs の Kernel::infer と Kernel::check が実装しており、第 5 章で一行ずつ読む。文脈は src/declaration.rs の Rust 型 Context = Vec<(String, Term)>、すなわち名前と型の対のベクトルで、末尾から探索するので、同じ名前についてはもっとも新しい仮定が勝つ。

演習

次の各判断を下から上へ処理するのはどの規則で、どんな前提を生むか。(a) Γ⊢λ(x:A). x:A→A\Gamma \vdash \tLam{x}{A}{x} : A \to AΓ⊢λ(x:A).x:A→A。(b) Γ⊢Sort 2:Sort 3\Gamma \vdash \Sort{2} : \Sort{3}Γ⊢Sort2:Sort3。(c) f:A→Bf : A \to Bf:A→B のときの Γ⊢f  a:B\Gamma \vdash f\;a : BΓ⊢fa:B。

解答

(a) T-Lam で、前提はある uuu について Γ⊢A:Sort u\Gamma \vdash A : \Sort{u}Γ⊢A:Sortu と Γ,x:A⊢x:A\Gamma, x : A \vdash x : AΓ,x:A⊢x:A であり、後者は T-Var による。結果の型は Π(x:A). A\tPi{x}{A}{A}Π(x:A).A で、束縛子の名前を除けば A→AA \to AA→A である。 (b) T-Sort で、前提は ⊢Γ;ok\ctxok{\Gamma}⊢Γ;ok のみ。 (c) T-App で、前提は Γ⊢f:Π(_:A). B\Gamma \vdash f : \tPi{\_}{A}{B}Γ⊢f:Π(_:A).B と Γ⊢a:A\Gamma \vdash a : AΓ⊢a:A である。_ は BBB に現れないので、結論は B[_↦a]=B\subst{B}{\_}{a} = BB[_↦a]=B となる。

T-Pi を使って、Π(P:Sort 0). P→P\tPi{P}{\Sort{0}}{P \to P}Π(P:Sort0).P→P と Π(A:Sort 1). A→A\tPi{A}{\Sort{1}}{A \to A}Π(A:Sort1).A→A の宇宙を計算せよ。

解答

前者では、Sort 0:Sort 1\Sort{0} : \Sort{1}Sort0:Sort1 なので u=1u = 1u=1 であり、P→P:Sort 0P \to P : \Sort{0}P→P:Sort0（再び T-Pi により、u=v=0u = v = 0u=v=0）なので v=0v = 0v=0 である。よって宇宙は Sort imax(1,0)=Sort 0\Sort{\imax(1, 0)} = \Sort{0}Sortimax(1,0)=Sort0 となり、すべての命題の上で量化する主張はそれ自体が命題である。 後者では u=2u = 2u=2 で、A→A:Sort 1A \to A : \Sort{1}A→A:Sort1 なので v=1v = 1v=1 であり、Sort imax(2,1)=Sort 2\Sort{\imax(2,1)} = \Sort{2}Sortimax(2,1)=Sort2 を得る。この非対称性は第 13 章で説明する。

覚えておくこと

  • 文脈は互いに異なる仮定 x:Ax : Ax:A の順序付きリストであり、判断 Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A は、その仮定のもとで ttt が型 AAA を持つことを言う。
  • 規則は項の種類ごとに一つと、それに計算と束縛変数の付け替えを除いて型を同一視する T-Conv がある。
  • T-App は仮定を使う場所であり、代入が起きる場所でもある一方、T-Conv は項の形から引き起こされない唯一の規則である。
  • 代入と定義的等価は第 III 部までブラックボックスとして扱う。

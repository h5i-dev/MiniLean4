附录 B

α 等价算法的正确性

第 11 章给出了 α 等价的两种定义：数学定义（允许给约束变量改名的最小同余关系）和算法定义（图 11.1 的规则，同步遍历两个项，按位置比较约束变量）。定理 11.1 说二者一致。本附录证明这一点。

思路

两种定义说的其实是同一件事：两个项的 de Bruijn 表示相同，也就是说，把每个约束变量换成它到自己绑定子的距离之后，二者形状相同。所以证明要经过第三种表示：无名的项表示。

  • 引理 B.1 表明算法比较的是无名形式。这几乎是显然的，因为图 11.1 的规则比较位置的方式与 de Bruijn 索引完全一样。
  • 引理 B.2 和 B.3 建立无名形式在改名下的两个性质。关键的一条是：给约束变量改名不改变无名形式。
  • 引理 B.4 利用这两条性质，表明数学定义比较的也是无名形式。
  • 定理 11.1 随之得出：把两条引理通过无名形式串起来即可。

这些证明都是对项的归纳，只有一处微妙之处：替换可能给绑定子改名，所以有些归纳必须对项的大小进行，而不是对结构进行。

无名项

无名项（nameless term）的构造方式与项相同，只是绑定子不带名字，约束变量写成数字 #i\#i#i：

d::=Sort u∣#i∣x∣Π d. d∣λ d. d∣d  dd ::= \Sort{u} \mid \#i \mid x \mid \Pi\,d.\,d \mid \lambda\,d.\,d \mid d\;dd::=Sortu∣#i∣x∣Πd.d∣λd.d∣dd

自由变量保留名字。数字 #i\#i#i 的意思是“由外层第 iii 个绑定子绑定的变量，从最内层的 000 开始数”。回忆第 11 章：对名字列表 EEE，idx(E,x)\mathrm{idx}(E, x)idx(E,x) 是 xxx 在 EEE 中最后一次出现的位置，从右边以 000 起数；若 x∉Ex \notin Ex∈/E 则无定义。

无名项的相等就是普通的语法相等。注意 ⌊t⌋E\db{t}{E}⌊t⌋E​ 与 ttt 的最外层形状相同，只是变量可能变成数字或保持名字。第 7 章引入的常量与宇宙一样保持不变，按名字比较；它们在下文中只增加一些平凡情形，故略去。

写下带非空 EEE 的 ⌊t⌋E\db{t}{E}⌊t⌋E​，描述的是作为子项的 ttt，它位于 EEE 所列的绑定子之下。整项的情形是 ⌊t⌋⋅\db{t}{\cdot}⌊t⌋⋅​，没有外层绑定子。保持 EEE 一般化的原因是，下面每个归纳都要穿过绑定子，而在绑定子之下，子项比它所来自的项多一个外层绑定子。

算法计算的是无名形式

第一条引理把图 11.1 的规则与无名形式联系起来。它的作用是把由规则定义的算法判断，换成两个项之间的等式，后者更容易推理。

关于改名的两个事实

第 11 章中 =α\alphaeq=α​ 的定义涉及替换：当 y∉FV(B)y \notin \FV(B)y∈/FV(B) 时，允许把 Π(x:A). B\tPi{x}{A}{B}Π(x:A).B 换成 Π(y:A). B[x↦y]\tPi{y}{A}{\subst{B}{x}{y}}Π(y:A).B[x↦y]。要把它与无名形式联系起来，需要知道给约束变量改名时 ⌊⋅⌋\db{\cdot}{}⌊⋅⌋​ 如何变化。两条引理提供这一点。

第一条说，⌊t⌋E\db{t}{E}⌊t⌋E​ 对 EEE 的依赖只通过 ttt 的自由变量。它的作用是技术性的：只要两个绑定子列表在相关变量上相合，就可以互相替换。

引理 B.2（相合）. 若对每个 v∈FV(t)v \in \FV(t)v∈FV(t) 都有 idx(E1,v)=idx(E2,v)\mathrm{idx}(E_1, v) = \mathrm{idx}(E_2, v)idx(E1​,v)=idx(E2​,v)（两边可以同时无定义），则 ⌊t⌋E1=⌊t⌋E2\db{t}{E_1} = \db{t}{E_2}⌊t⌋E1​​=⌊t⌋E2​​。

对 ttt 归纳，同时对所有 E1E_1E1​ 和 E2E_2E2​。变量情形正是假设本身：自由变量 vvv 在两边变成同一个数字，或保持同一个名字。宇宙不受 EEE 影响；应用由两个部分的归纳假设得出。

在绑定子 xxx 之下，列表 E1,xE_1, xE1​,x 和 E2,xE_2, xE2​,x 在体的自由变量上仍然相合。变量 xxx 在两边的位置都是 000。体的其他任何自由变量 vvv 都是 ttt 的自由变量，由假设，它在 E1E_1E1​ 和 E2E_2E2​ 中的位置相同；追加 xxx 使这个位置在两边各加一，或者在两边都保持无定义。于是对体可用归纳假设；注记部分则用原列表的归纳假设处理。

第二条引理完成本附录的主要工作：给绑定子改名不改变无名形式。它针对位于任意深度的绑定子来陈述，绑定子之前是列表 EEE，之后是列表 E′E'E′，因为归纳要继续深入更多绑定子。

我们要用到一个事实：用变量替换变量保持项的大小，即使沿途给绑定子改了名；这是对替换定义的例行归纳。

引理 B.3（改名）. 设 y≠xy \neq xy=x，y∉FV(B)y \notin \FV(B)y∈/FV(B)，且 x,y∉E′x, y \notin E'x,y∈/E′。则对每个列表 EEE 都有 ⌊B⌋E,x,E′=⌊B[x↦y]⌋E,y,E′\db{B}{E, x, E'} = \db{\subst{B}{x}{y}}{E, y, E'}⌊B⌋E,x,E′​=⌊B[x↦y]⌋E,y,E′​。

对 BBB 的大小归纳，同时对所有 EEE 和 E′E'E′。记 Lx=E,x,E′L_x = E, x, E'Lx​=E,x,E′ 和 Ly=E,y,E′L_y = E, y, E'Ly​=E,y,E′；它们恰有一个条目不同，且位于同一位置。

若 B=xB = xB=x，则 B[x↦y]=y\subst{B}{x}{y} = yB[x↦y]=y。由于 x,y∉E′x, y \notin E'x,y∈/E′，xxx 在 LxL_xLx​ 中的最后一次出现和 yyy 在 LyL_yLy​ 中的最后一次出现都是那个特殊条目，所以 idx(Lx,x)\mathrm{idx}(L_x, x)idx(Lx​,x) 和 idx(Ly,y)\mathrm{idx}(L_y, y)idx(Ly​,y) 都等于 E′E'E′ 的长度，两个无名形式是同一个数字。

宇宙和应用由定义和归纳假设直接得出。

定义计算的也是无名形式

有了这两条改名事实，我们可以证明 =α\alphaeq=α​ 的数学定义同样归结为无名形式的相等。两个方向的证法不同：一个利用 =α\alphaeq=α​ 作为同余关系的最小性，另一个对大小归纳。

引理 B.4（定义比较的是无名形式）. 若按第 11 章定义的意义有 s=αts \alphaeq ts=α​t，则对每个 EEE 都有 ⌊s⌋E=⌊t⌋E\db{s}{E} = \db{t}{E}⌊s⌋E​=⌊t⌋E​。反之，若对某个 EEE 有 ⌊s⌋E=⌊t⌋E\db{s}{E} = \db{t}{E}⌊s⌋E​=⌊t⌋E​，则 s=αts \alphaeq ts=α​t。

第一部分. 令 s∼ts \sim ts∼t 表示对每个 EEE 都有 ⌊s⌋E=⌊t⌋E\db{s}{E} = \db{t}{E}⌊s⌋E​=⌊t⌋E​。这个关系是等价关系，因为相等是。它是同余关系，因为 ⌊⋅⌋\db{\cdot}{}⌊⋅⌋​ 是逐构造子定义的：如果两个项的各部分在相应列表下的无名形式相等，那么这两个项的无名形式也相等。最后，∼\sim∼ 包含 =α\alphaeq=α​ 的定义等式：若 y∉FV(B)y \notin \FV(B)y∈/FV(B)，则

⌊Π(x:A). B⌋E=Π ⌊A⌋E. ⌊B⌋E,xand⌊Π(y:A). B[x↦y]⌋E=Π ⌊A⌋E. ⌊B[x↦y]⌋E,y,\db{\tPi{x}{A}{B}}{E} = \Pi\,\db{A}{E}.\,\db{B}{E, x} \qquad\text{and}\qquad \db{\tPi{y}{A}{\subst{B}{x}{y}}}{E} = \Pi\,\db{A}{E}.\,\db{\subst{B}{x}{y}}{E, y},⌊Π(x:A).B⌋E​=Π⌊A⌋E​.⌊B⌋E,x​and⌊Π(y:A).B[x↦y]⌋E​=Π⌊A⌋E​.⌊B[x↦y]⌋E,y​,

而两个体由引理 B.3（取 E′E'E′ 为空）相等；y=xy = xy=x 的情形平凡，因为此时两个项完全相同。λ\lambdaλ 的情形同理。由于 =α\alphaeq=α​ 是包含该等式的最小同余关系，而 ∼\sim∼ 是包含它的一个同余关系，所以 s=αts \alphaeq ts=α​t 蕴涵 s∼ts \sim ts∼t。

第二部分. 对 sss 的大小归纳，同时对所有 ttt 和 EEE，假设 ⌊s⌋E=⌊t⌋E\db{s}{E} = \db{t}{E}⌊s⌋E​=⌊t⌋E​。

若 sss 是变量，则 ttt 也是，因为其他形状的无名形式绝不会是数字或名字。若两个无名形式都是数字 #i\#i#i，则两个变量都是 EEE 中位置 iii 处的条目，所以 s=ts = ts=t。若两个都是名字，则直接有 s=ts = ts=t。无论哪种情形，由自反性得 s=αts \alphaeq ts=α​t。

宇宙直接相等。对于应用，两部分的无名形式各自相等，于是归纳假设给出每部分的 =α\alphaeq=α​，再由 =α\alphaeq=α​ 的同余性质得到整体的结论。

设 s=Π(x:A). Bs = \tPi{x}{A}{B}s=Π(x:A).B，于是 t=Π(y:A′). B′t = \tPi{y}{A'}{B'}t=Π(y:A′).B′，且 ⌊A⌋E=⌊A′⌋E\db{A}{E} = \db{A'}{E}⌊A⌋E​=⌊A′⌋E​、⌊B⌋E,x=⌊B′⌋E,y\db{B}{E, x} = \db{B'}{E, y}⌊B⌋E,x​=⌊B′⌋E,y​。归纳假设给出 A=αA′A \alphaeq A'A=α​A′。对于体，选取 z∉FV(B)∪FV(B′)∪{x,y}z \notin \FV(B) \cup \FV(B') \cup \{x, y\}z∈/FV(B)∪FV(B′)∪{x,y}。引理 B.3（取 E′E'E′ 为空）给出 ⌊B⌋E,x=⌊B[x↦z]⌋E,z\db{B}{E, x} = \db{\subst{B}{x}{z}}{E, z}⌊B⌋E,x​=⌊B[x↦z]⌋E,z​ 和 ⌊B′⌋E,y=⌊B′[y↦z]⌋E,z\db{B'}{E, y} = \db{\subst{B'}{y}{z}}{E, z}⌊B′⌋E,y​=⌊B′[y↦z]⌋E,z​，所以

⌊B[x↦z]⌋E,z=⌊B′[y↦z]⌋E,z.\db{\subst{B}{x}{z}}{E, z} = \db{\subst{B'}{y}{z}}{E, z}.⌊B[x↦z]⌋E,z​=⌊B′[y↦z]⌋E,z​.

由于 B[x↦z]\subst{B}{x}{z}B[x↦z] 的大小与 BBB 相同，小于 sss 的大小，归纳假设给出 B[x↦z]=αB′[y↦z]\subst{B}{x}{z} \alphaeq \subst{B'}{y}{z}B[x↦z]=α​B′[y↦z]。于是

Π(x:A). B  =α  Π(z:A). B[x↦z]  =α  Π(z:A′). B′[y↦z]  =α  Π(y:A′). B′,\tPi{x}{A}{B} \;\alphaeq\; \tPi{z}{A}{\subst{B}{x}{z}} \;\alphaeq\; \tPi{z}{A'}{\subst{B'}{y}{z}} \;\alphaeq\; \tPi{y}{A'}{B'},Π(x:A).B=α​Π(z:A).B[x↦z]=α​Π(z:A′).B′[y↦z]=α​Π(y:A′).B′,

定理 11.1 的证明

定理 11.1（算法 α 等价的正确性）. 对所有项 sss 和 ttt，按第 11 章定义的意义 s=αts \alphaeq ts=α​t，当且仅当 ⋅ ;⋅⊢s=αt\cdot\,;\cdot \vdash s \alphaeq t⋅;⋅⊢s=α​t 可由图 11.1 的规则推导。

若 s=αts \alphaeq ts=α​t，则由引理 B.4 的第一部分（取 EEE 为空）得 ⌊s⌋⋅=⌊t⌋⋅\db{s}{\cdot} = \db{t}{\cdot}⌊s⌋⋅​=⌊t⌋⋅​，再由引理 B.1 得 ⋅ ;⋅⊢s=αt\cdot\,;\cdot \vdash s \alphaeq t⋅;⋅⊢s=α​t。

反之，若 ⋅ ;⋅⊢s=αt\cdot\,;\cdot \vdash s \alphaeq t⋅;⋅⊢s=α​t，则由引理 B.1 得 ⌊s⌋⋅=⌊t⌋⋅\db{s}{\cdot} = \db{t}{\cdot}⌊s⌋⋅​=⌊t⌋⋅​，再由引理 B.4 的第二部分得 s=αts \alphaeq ts=α​t。

定理针对整项、以空绑定子列表来陈述，因为内核就是这样调用比较的。引理 B.1 更一般，描述了算法在每次递归调用时计算的东西；阅读 src/substitution.rs 中 alpha 的实现时正需要它：该函数携带的两个约束名向量就是 E1E_1E1​ 和 E2E_2E2​，而 binder_distance 计算的是 idx\mathrm{idx}idx。

要点回顾

  • α 等价的两种定义计算的是同一件事：de Bruijn（无名）形式的相等。无名形式是连接二者的桥梁。
  • 算法逐条规则地直接匹配无名形式（引理 B.1）。
  • 关于数学定义的关键事实是：给约束变量改名不改变无名形式（引理 B.3）；这需要对大小归纳，因为替换本身可能给绑定子改名。
  • 使用 de Bruijn 索引的内核免费获得这条定理：α 等价的项在语法上完全相同。

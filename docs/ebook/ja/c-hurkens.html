Hurkens のパラドックス

第 13 章 は、自分自身を含む単一の宇宙があると型理論が整合的でなくなると述べたのは、型 Π(p:Type). p\tPi{p}{\mathsf{Type}}{p}Π(p:Type).p をもつ閉じた項、つまりあらゆる命題の証明が存在するからである。この付録ではその項を完全な形で与え、背後にある考え方を説明し、規則 Type:Type\mathsf{Type} : \mathsf{Type}Type:Type がどこで使われるかを正確に示すので、宇宙の階層がなぜこの構成を阻むのかが見えるはずである。

この構成は Girard によるもので、集合論の Burali-Forti のパラドックスを Type:Type\mathsf{Type} : \mathsf{Type}Type:Type をもつ型理論に移植したものである [Girard 1972]。以下に示す項は Hurkens による簡略版 [Hurkens 1995] で、1 ページに収まり、Π\PiΠ、λ\lambdaλ、適用以外は何も使わない。

型理論における冪集合

関数 p:S→Typep : S \to \mathsf{Type}p:S→Type は SSS 上の述語、言い換えれば SSS の部分集合と読み、p  xp\;xpx に証明がある要素 xxx がその元である。そのような述語すべての型が SSS の冪集合（power set）である。

℘S  =  S→Type.\wp S \;=\; S \to \mathsf{Type}.℘S=S→Type.

集合論では、Cantor の定理により ℘S\wp S℘S は常に SSS より真に大きいので、どんな集合も自分の冪集合の複製を含まず、二重冪集合ならなおさらである。パラドックスは、これに反して ℘℘U\wp\wp U℘℘U の複製を含む型 UUU の上に組み立てられる。すなわち、UUU の部分集合の族を UUU の一つの要素に詰め込む関数 τ:℘℘U→U\tau : \wp\wp U \to Uτ:℘℘U→U と、それを再び取り出す関数 σ:U→℘℘U\sigma : U \to \wp\wp Uσ:U→℘℘U がある。型

U  =  Π(X:Type). ((℘℘X→X)→℘℘X)U \;=\; \tPi{X}{\mathsf{Type}}{\bigl((\wp\wp X \to X) \to \wp\wp X\bigr)}U=Π(X:Type).((℘℘X→X)→℘℘X)

Type : Type が使われる場所

tHt_{\mathrm{H}}tH​ の型付けの各ステップは、一つを除いてすべて普通のものである。σ=λ(s:U). s  U  τ\sigma = \tLam{s}{U}{s\;U\;\tau}σ=λ(s:U).sUτ では、変数 s:Us : Us:U が型 UUU 自身に適用され、sss の型は Π(X:Type). ⋯\tPi{X}{\mathsf{Type}}{\cdots}Π(X:Type).⋯ で始まるので、T-App は U:TypeU : \mathsf{Type}U:Type を要求する。ところが UUU は Type\mathsf{Type}Type にわたって量化する Π\PiΠ 型であり、宇宙の階層をもつ体系では、そのような型は量化対象の宇宙より一つ上のレベルに属する。

カーネルで再現する

カーネルがこの項を受理し、また拒否する様子を自分で確かめられる。変更すべき規則は T-Sort だけで、これは src/typecheck.rs の infer にある Term::Sort(u) の場合分けで実装されている。

// T-Sort、出荷時の形: どの宇宙も一つ上の宇宙に属する。
Term::Sort(u) => Ok(Term::Sort(u.checked_add(1).ok_or("universe overflow")?)),

この変更を残したままにしてはいけない。カーネルが整合的でなくなるだけでなく、停止性も壊れる。第 13 章 で説明するように tHt_{\mathrm{H}}tH​ には正規形がないので、変更後のカーネルに正規化を頼むと、第 12 章 の簡約の燃料が尽きるまで走り続ける。

正規形が存在しない理由

第 14 章 は、型 Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P をもつ正規な閉じた項が存在しないことを示して、本来の体系の整合性を証明する。その証明のうち正規項の形を分析する部分は強正規化を使わず、Type:Type\mathsf{Type} : \mathsf{Type}Type:Type のもとでもそのまま通る。したがって、もし tHt_{\mathrm{H}}tH​ に正規形があれば、それは型 ⊥\bot⊥ をもつ閉じた正規項になるが、そのようなものは存在しえない。型保存性も成り立つので、簡約によって型 ⊥\bot⊥ から逃れることもできない。残る可能性はただ一つ、tHt_{\mathrm{H}}tH​ が永遠に簡約され続けることであり、強正規化が破れ、それとともに型検査器の停止性も失われる。Girard のパラドックスは論理上の欠陥であるだけでなく計算上の欠陥でもあり、第 13 章 の宇宙の設計が、論理と同じくらいアルゴリズムにとっても重要である理由はここにある。

覚えておくこと

  • Type:Type\mathsf{Type} : \mathsf{Type}Type:Type のもとでは、型 UUU は自分もその一つでありながらすべての型にわたって量化するので、自分自身の二重冪集合の複製を含むが、集合にはそれができない。
  • Hurkens の項 tHt_{\mathrm{H}}tH​ はこれを Burali-Forti のパラドックスに仕立て、すべての帰納的述語の族を詰め込んだ Ω\OmegaΩ は、整礎でありながら自分自身より下にある。
  • 規則 Type:Type\mathsf{Type} : \mathsf{Type}Type:Type が使われるのはただ一か所、σ\sigmaσ の中の適用 s  Us\;UsU であり、宇宙の階層はこの適用に型が付かないようにする。
  • この項には正規形がないので、パラドックスは整合性だけでなくカーネルの停止性も壊す。

第 3 章

类型规则

内核的任务是判定“项 ttt 具有类型 AAA”这一判断。本章用一小组推理规则定义这个判断：每种项一条规则，外加一条允许在类型内部进行计算的规则。自底向上地读每条规则，它就成了检查项的一套步骤，而这套步骤在第 5 章变成算法。

上下文与判断

像 f  pf\;pfp 这样的项无法孤立地检查：它的类型取决于 fff 和 ppp 是什么。上下文（context）Γ\GammaΓ 记录这些信息。它是一个有序的假设列表

Γ  =  x1:A1,  x2:A2,  …,  xn:An,\Gamma \;=\; x_1 : A_1,\; x_2 : A_2,\; \ldots,\; x_n : A_n,Γ=x1​:A1​,x2​:A2​,…,xn​:An​,

给出作用域内每个变量的类型，dom(Γ)\dom(\Gamma)dom(Γ) 表示名字的集合 {x1,…,xn}\{x_1, \ldots, x_n\}{x1​,…,xn​}。空上下文写作 ⋅\cdot⋅。

顺序很重要。靠后的类型可以提到靠前的变量，比如 P:Sort 0,  h:PP : \Sort{0},\; h : PP:Sort0,h:P：只有先知道 PPP 是命题，假设 h:Ph : Ph:P 才有意义。我们会要求上下文中的名字互不相同，这样上下文就能当作一个从名字到类型的字典来使用；不过这个字典的各条目按顺序相互依赖。

两个判断是一起定义的。

  • ⊢Γ;ok\ctxok{\Gamma}⊢Γ;ok 表示上下文 Γ\GammaΓ 是良构的（well formed）：每条假设的类型在它之前的上下文中都是一个类型。
  • Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A 表示在 Γ\GammaΓ 的假设之下，项 ttt 具有类型 AAA。

透过 Curry-Howard 的视角，Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A 说的是：ttt 是从假设 Γ\GammaΓ 出发对 AAA 的证明。

有两条规则用到了项上的操作，接下来几章把它们当作黑箱处理。

替换。T-App 用 B[x↦a]\subst{B}{x}{a}B[x↦a] 表示把 BBB 中 xxx 的每个自由出现替换为 aaa 的结果。例如，(P→P)[P↦Q]=Q→Q\subst{(P \to P)}{P}{Q} = Q \to Q(P→P)[P↦Q]=Q→Q。在绑定子内部替换名字需要小心，第 11 章会解释；在那之前，直观含义就够用了。

定义相等。当 AAA 和 BBB 在某种内核可以机械判定的意义下是“同一个类型”时，T-Conv 写作 A≡BA \conv BA≡B。两类差异会被忽略。

  • 约束变量的名字。Π(P:Sort 0). P→P\tPi{P}{\Sort{0}}{P \to P}Π(P:Sort0).P→P 和 Π(Q:Sort 0). Q→Q\tPi{Q}{\Sort{0}}{Q \to Q}Π(Q:Sort0).Q→Q 陈述的是同一个命题。仅有这种差异的项是 α 等价的，写作 A=αBA \alphaeq BA=α​B。
  • 计算。若 Id=λ(X:Sort 0). X\mathit{Id} = \tLam{X}{\Sort{0}}{X}Id=λ(X:Sort0).X，则 Id  P\mathit{Id}\;PIdP 把 PPP 代入 XXX 后计算得到 PPP，因此 Id  P\mathit{Id}\;PIdP 的证明应当算作 PPP 的证明。计算步骤 (λ(x:A). t)  s→βt[x↦s](\tLam{x}{A}{t})\;s \betared \subst{t}{x}{s}(λ(x:A).t)s→β​t[x↦s] 称为 β 归约。

内核判定 A≡BA \conv BA≡B 的方法是把两边尽可能地计算下去，再检查结果是否 α 等价。第 12 章给出精确定义。

解读规则

规则最好自底向上地读，当作一套步骤：要建立结论，就先建立前提。

C-Empty 与 C-Ext。上下文一次加入一条假设，每条新假设的类型本身必须是一个类型。附加条件 x∉dom(Γ)x \notin \dom(\Gamma)x∈/dom(Γ) 禁止两条假设同名。由于约束变量的名字无关紧要，这个条件并不限制什么：会冲突的绑定子总可以先改名。第 11 章展示了跳过这个条件的内核会出什么问题。

T-Sort。每个宇宙都住在下一个宇宙里：Sort 0:Sort 1\Sort{0} : \Sort{1}Sort0:Sort1，Sort 1:Sort 2\Sort{1} : \Sort{2}Sort1:Sort2，依此类推。第 13 章解释为什么宇宙不能是自己的类型。

T-Var。变量的类型就是上下文赋予它的类型。从逻辑上看：使用一条假设。

T-Pi。若 AAA 是类型，且在假设 x:Ax : Ax:A 之后 BBB 是类型，则 Π(x:A). B\tPi{x}{A}{B}Π(x:A).B 是类型。所得宇宙为 imax(u,v)\imax(u, v)imax(u,v)：当 v=0v = 0v=0 时为 000，否则为 max⁡(u,v)\max(u, v)max(u,v)。用文字说：只要函数体是命题，Π\PiΠ 类型就是命题，无论它量化的是什么；否则它住在两个宇宙中较大的那个。从逻辑上看，这条规则规定了 A→BA \to BA→B 和 ∀x:A. B\forall x{:}A.\,B∀x:A.B 何时是良构的陈述。

T-Lam。要构造从 AAA 到 BBB 的函数，先假设 x:Ax : Ax:A，再构造类型为 BBB 的项 ttt。函数体的类型 BBB 可以提到 xxx，并原样保留在所得的 Π\PiΠ 类型中，依赖性正是从这里进入的。从逻辑上看，这是蕴含和全称量词的引入规则：要证明 A→BA \to BA→B，就假设 AAA 并证明 BBB。

T-App。若 fff 把每个 x:Ax : Ax:A 映射到 BBB 的一个元素，且 a:Aa : Aa:A，则 f  af\;afa 的类型是把 BBB 中的 xxx 替换为 aaa 的结果。当 BBB 不提到 xxx 时，这就是肯定前件（modus ponens）：由 A→BA \to BA→B 和 AAA 推出 BBB。反之，这是对全称陈述的实例化。例如，若 f:Π(n:Nat). n+0=nf : \tPi{n}{\Nat}{n + 0 = n}f:Π(n:Nat).n+0=n，则 f  3:3+0=3f\;3 : 3 + 0 = 3f3:3+0=3（自然数在第 7 章登场）。

T-Conv。在计算意义下相等的类型可以互换：由 h:Id  Ph : \mathit{Id}\;Ph:IdP 可以得出 h:Ph : Ph:P。前提 Γ⊢B:Sort u\Gamma \vdash B : \Sort{u}Γ⊢B:Sortu 保证新类型本身是一个类型。这是唯一一条使用时机不由 ttt 的形状决定的规则，这一点对第 5 章的算法很重要。

每条规则都是关于函数的一点常识。T-Lam 说怎样构造函数；T-App 说怎样使用函数；T-Pi 说函数类型何时有意义；T-Var 和 T-Sort 说基本的东西是什么；T-Conv 说在类型内部计算不改变它的含义。规则里没有任何专门“逻辑”的成分。逻辑是透过 Curry-Howard 解读这些规则的结果，第 4 章会把这一点讲精确。

应用为何重要

人们容易以为，有趣的规则是那些构造东西的规则（T-Lam、T-Pi），而 T-App 只是记账。事实恰恰相反。没有 T-App，假设只能被原样返回，却永远无法被使用。粗略地说，那时可证的命题只剩下结论恰好就是某条假设的那些，比如 P→Q→PP \to Q \to PP→Q→P。复合律

(P→Q)→(Q→R)→P→R,(P \to Q) \to (Q \to R) \to P \to R,(P→Q)→(Q→R)→P→R,

的证明是 λ(f:P→Q). λ(g:Q→R). λ(p:P). g (f p)\tLam{f}{P \to Q}{\tLam{g}{Q \to R}{\tLam{p}{P}{g\,(f\,p)}}}λ(f:P→Q).λ(g:Q→R).λ(p:P).g(fp)，它先应用 fff 再应用 ggg。凡是不止于复述假设的证明都要经过 T-App，而在依赖类型论中，T-App 也是替换发生的地方，因此大部分微妙之处都在这里。

内核构建的就是这棵树。下面每个节点是规则的一次应用，标有它建立的判断；切换到调用视图，可以自顶向下地把它读成生成这棵树的递归过程。换成你自己的项，看看哪些规则会被触发。

两点观察。第一，树的形状跟随项的形状：根是一个 λ\lambdaλ，其下又是一个 λ\lambdaλ，叶子是变量。第二，根处的类型是 Π(P:Sort 0). Π(h:P). P\tPi{P}{\Sort{0}}{\tPi{h}{P}{P}}Π(P:Sort0).Π(h:P).P，而所陈述的命题是 Π(P:Sort 0). P→P\tPi{P}{\Sort{0}}{P \to P}Π(P:Sort0).P→P。两者只差一个约束变量的名字（hhh 与箭头的匿名 _），所以它们是 α 等价的，由 T-Conv 弥合这一差距。第 6 章会用算法重新审视这个例子。

练习

自底向上地应用时，下列判断各由哪条规则处理，产生哪些前提？(a) Γ⊢λ(x:A). x:A→A\Gamma \vdash \tLam{x}{A}{x} : A \to AΓ⊢λ(x:A).x:A→A。(b) Γ⊢Sort 2:Sort 3\Gamma \vdash \Sort{2} : \Sort{3}Γ⊢Sort2:Sort3。(c) Γ⊢f  a:B\Gamma \vdash f\;a : BΓ⊢fa:B，其中 f:A→Bf : A \to Bf:A→B。

解答

(a) T-Lam，前提是对某个 uuu 有 Γ⊢A:Sort u\Gamma \vdash A : \Sort{u}Γ⊢A:Sortu，以及 Γ,x:A⊢x:A\Gamma, x : A \vdash x : AΓ,x:A⊢x:A；后者由 T-Var 处理。所得类型是 Π(x:A). A\tPi{x}{A}{A}Π(x:A).A，在不计绑定子名字的意义下就是 A→AA \to AA→A。 (b) T-Sort，唯一的前提是 ⊢Γ;ok\ctxok{\Gamma}⊢Γ;ok。 (c) T-App，前提是 Γ⊢f:Π(_:A). B\Gamma \vdash f : \tPi{\_}{A}{B}Γ⊢f:Π(_:A).B 和 Γ⊢a:A\Gamma \vdash a : AΓ⊢a:A。结论是 B[_↦a]=B\subst{B}{\_}{a} = BB[_↦a]=B，因为 _ 不出现在 BBB 中。

用 T-Pi 计算 Π(P:Sort 0). P→P\tPi{P}{\Sort{0}}{P \to P}Π(P:Sort0).P→P 和 Π(A:Sort 1). A→A\tPi{A}{\Sort{1}}{A \to A}Π(A:Sort1).A→A 的宇宙。

解答

对前者，Sort 0:Sort 1\Sort{0} : \Sort{1}Sort0:Sort1，故 u=1u = 1u=1；又 P→P:Sort 0P \to P : \Sort{0}P→P:Sort0（再次用 T-Pi，取 u=v=0u = v = 0u=v=0），故 v=0v = 0v=0。于是宇宙为 Sort imax(1,0)=Sort 0\Sort{\imax(1, 0)} = \Sort{0}Sortimax(1,0)=Sort0：对所有命题量化的陈述本身仍是命题。 对后者，u=2u = 2u=2，且 A→A:Sort 1A \to A : \Sort{1}A→A:Sort1，故 v=1v = 1v=1，得到 Sort imax(2,1)=Sort 2\Sort{\imax(2,1)} = \Sort{2}Sortimax(2,1)=Sort2。第 13 章解释这种不对称。

要点回顾

  • 上下文是互不重名的假设 x:Ax : Ax:A 的有序列表；判断 Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A 表示在这些假设下 ttt 具有类型 AAA。
  • 每种项一条规则，外加 T-Conv，它把在计算和约束变量改名意义下相等的类型视为同一。
  • T-App 是使用假设、发生替换的地方；T-Conv 是唯一不由项的形状触发的规则。
  • 替换和定义相等在第三部分之前当作黑箱。

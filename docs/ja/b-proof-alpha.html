付録 B

α 同値アルゴリズムの正しさ

第 11 章では α 同値に二つの定義を与えた。数学的な定義（束縛変数の改名を許す最小の合同関係）と、アルゴリズム的な定義（図 11.1 の規則。二つの項を足並みを揃えてたどり、束縛変数を位置で比較する）である。定理 11.1 は両者が一致すると述べており、本付録ではそれを証明する。

考え方

結局のところ、二つの定義は同じことを言っており、それは二つの項が同じ de Bruijn 表現を持つ、すなわち、各束縛変数をその束縛子までの距離に置き換えたときに同じ形になる、ということである。そこで証明は、項の第三の表現である名前なし表現を経由する。

  • 補題 B.1 は、アルゴリズムが名前なし形を比較していることを示す。図 11.1 の規則は de Bruijn インデックスとまったく同じように位置を比較するので、これはほぼ自明である。
  • 補題 B.2 と B.3 は、改名のもとで名前なし形がどう振る舞うかについて、二つの事実を確立し、鍵となるのは、束縛変数を改名しても名前なし形は変わらないという事実である。
  • 補題 B.4 は、これら二つの事実を使って、数学的な定義もまた名前なし形を比較していることを示す。
  • 定理 11.1 は、名前なし形を介して二つの補題をつなげば従う。

証明は項に関する帰納法だが、一つ微妙な点があり、代入は束縛子を改名することがあるので、いくつかの帰納法は項の構造ではなくサイズに関して行わなければならない。

改名についての二つの事実

第 11 章の =α\alphaeq=α​ の定義には、y∉FV(B)y \notin \FV(B)y∈/FV(B) のとき、Π(x:A). B\tPi{x}{A}{B}Π(x:A).B を Π(y:A). B[x↦y]\tPi{y}{A}{\subst{B}{x}{y}}Π(y:A).B[x↦y] で置き換えることを許すので、代入が関わる。これを名前なし形と関係づけるには、束縛変数を改名したとき ⌊⋅⌋\db{\cdot}{}⌊⋅⌋​ がどう振る舞うかを知る必要があり、二つの補題がそれを与える。

であり、本体は E′E'E′ を空とした補題 B.3 により等しい。y=xy = xy=x の場合は二つの項が同一なので自明であり、λ\lambdaλ についても同じである。=α\alphaeq=α​ はこの等式を含む最小の合同関係であり、∼\sim∼ はこの等式を含む合同関係なので、s=αts \alphaeq ts=α​t ならば s∼ts \sim ts∼t である。

後半. ⌊s⌋E=⌊t⌋E\db{s}{E} = \db{t}{E}⌊s⌋E​=⌊t⌋E​ を仮定し、sss のサイズに関する帰納法により、すべての ttt と EEE について示す。

定理 11.1 の証明

定理 11.1（アルゴリズム的 α 同値の正しさ）. すべての項 sss と ttt について、第 11 章の定義の意味で s=αts \alphaeq ts=α​t であることと、⋅ ;⋅⊢s=αt\cdot\,;\cdot \vdash s \alphaeq t⋅;⋅⊢s=α​t が図 11.1 の規則で導出可能であることは同値である。

s=αts \alphaeq ts=α​t ならば、補題 B.4 の前半（EEE を空として）により ⌊s⌋⋅=⌊t⌋⋅\db{s}{\cdot} = \db{t}{\cdot}⌊s⌋⋅​=⌊t⌋⋅​ であり、補題 B.1 により ⋅ ;⋅⊢s=αt\cdot\,;\cdot \vdash s \alphaeq t⋅;⋅⊢s=α​t である。

逆に ⋅ ;⋅⊢s=αt\cdot\,;\cdot \vdash s \alphaeq t⋅;⋅⊢s=α​t ならば、補題 B.1 により ⌊s⌋⋅=⌊t⌋⋅\db{s}{\cdot} = \db{t}{\cdot}⌊s⌋⋅​=⌊t⌋⋅​ であり、補題 B.4 の後半により s=αts \alphaeq ts=α​t である。

定理は、束縛子リストが空の項全体について述べているが、これはカーネルが比較を呼び出すのがその形だからである。補題 B.1 はより一般的で、アルゴリズムが各再帰呼び出しで何を計算しているかを記述するので、src/substitution.rs の alpha の実装を読むときに必要なのはこちらである。実装が携える二つの束縛名のベクタが E1E_1E1​ と E2E_2E2​ であり、binder_distance が idx\mathrm{idx}idx を計算する。

覚えておくこと

  • α 同値の二つの定義は同じもの、すなわち de Bruijn（名前なし）形の等しさを計算しており、名前なし形が両者をつなぐ橋である。
  • アルゴリズムは名前なし形を規則ごとに直接照合する（補題 B.1）。
  • 数学的な定義についての鍵となる事実は、束縛変数を改名しても名前なし形が変わらないこと（補題 B.3）であり、代入自身が束縛子を改名しうるので、これにはサイズに関する帰納法が要る。
  • de Bruijn インデックスを使うカーネルは、α 同値な項が構文的に同一なので、この定理をただで手に入れる。

第 14 章

体系の性質

型検査はなぜ必ず停止するのでしょうか。また、コア体系で False を証明できないのはなぜでしょうか。答えるには型付けと簡約についての定理が必要で、Rust の実装を眺めるだけではわかりません。この章では必要な定理を挙げて整合性の証明の筋道を示し、完全な証明は付録 D に回します。

定理が扱う体系

以下の定理が扱うのは核となる体系です。図 3.1 の規則に第 13 章の宇宙を加え、第 II 部の定数を取り除いたものを指します。これは Barendregt のいう純粋型システム（Pure Type System）の一つで、Calculus of Constructions [Coquand 1988] の非述語的な Sort 0\Sort{0}Sort0 の上に述語的な宇宙の階層を重ねた形をしており、Luo の Extended Calculus of Constructions [Luo 1990] に近い体系です。最初の三つの性質は、関数的な純粋型システムならどれでも成り立ちます [Barendregt 1992]。一方、強正規化は非述語性があると格段に難しくなり、Girard の可約性候補（reducibility candidates）の方法が必要です [Girard 1972; Coquand 1988; Luo 1990]。帰納型を加えると何が変わるかは章末で述べます。

四つの性質

定理 14.1（型の一意性）. Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A かつ Γ⊢t:B\Gamma \vdash t : BΓ⊢t:B ならば、A≡BA \conv BA≡B です。

項の型は、変換を除いて一つに定まります。Infer\InferInfer はこの性質に頼っています。計算すべき答えが一つしかないので、Check\CheckCheck はその答えと比べるだけで済み、別の導出なら変換できない別の型が出てきたのではないかと心配する必要がありません。

定理 14.2（型の正しさ）. Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A ならば、ある uuu について A=Sort uA = \Sort{u}A=Sortu であるか、またはある uuu について Γ⊢A:Sort u\Gamma \vdash A : \Sort{u}Γ⊢A:Sortu です。

正しく型付けされた項の型は、それ自身が型です（宇宙の場合もあります。宇宙は T-Sort によって型を持ちますが、型として書き下す必要はありません）。そのため Infer\InferInfer の結果はいつでも InferSort\InferSortInferSort に渡し直せ、アルゴリズムが組み立てる文脈は整形式のまま保たれます。

定理 14.3（型保存性）. Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A かつ t→βt′t \betared t't→β​t′ ならば、Γ⊢t′:A\Gamma \vdash t' : AΓ⊢t′:A です。

計算は型を保存します。T-Conv が正当なのも、正規化によって等しさを判定するという戦略全体が正当なのも、この性質のおかげです。項を簡約しても型は変わらないので、正規形どうしを比べれば、本来比べたいものを正しく比べたことになります。

定理 14.4（強正規化）. Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A ならば、ttt から始まる β 簡約の列はすべて有限です。

正しく型付けされた項は、どの順序で簡約しても正規形にたどり着きます。四つのうちで最も深い定理です。Whnf\WhnfWhnf と Normalize\NormalizeNormalize、ひいては IsDefEq\IsDefEqIsDefEq と Infer\InferInfer が正しく型付けされた入力に対して停止するのはこの定理のおかげで、次節で見るように整合性もこの定理に支えられています。

図 14.1. メタ理論の組み合わさり方。

これらを合わせると、カーネルに求める二つの保証が得られます。

  • 決定可能性。 アルゴリズム 5.1 はどんな入力に対しても停止するので、証明が正しいかどうかはつねに判定できます。
  • 整合性。 False を証明する閉じた項は存在しません。

強正規化が述べているのは、正しく型付けされた項のことだけです。ところがカーネルは型の付かない項を受け取ることもありますし、Whnf\WhnfWhnf は型付けが確立する前、推論の途中でも呼ばれます。実装がステップ予算を持つのはそのためで、定理の守備範囲の外にある入力に対しては、ステップ予算が工学的に定理の代わりを務めます。

整合性

定理 14.5（整合性）. ⋅⊢t:Π(P:Sort 0). P\cdot \vdash t : \tPi{P}{\Sort{0}}{P}⋅⊢t:Π(P:Sort0).P となる閉じた項 ttt は存在しません。

論証は二つの段階に分かれ、細部に立ち入らなくても全体の形はつかめます。

正規形への帰着。 強正規化により、そのような項 ttt は正規形 nnn を持ち、型保存性により nnn も同じ型を持ちます。したがって、型 Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P を持つ正規な閉じた項が存在しないことを示せば十分です。定理 14.4 を使うのはこの段階なので、難しさはすべてここに集中しています。

正規形の解析。 正規な項は、宇宙、Π\PiΠ、λ\lambdaλ、または変数にいくつかの引数を適用したもの（中立項（neutral term））のいずれかです。スコープ内に変数がないので、中立項にはなりえません。また、宇宙と Π\PiΠ 型の型は宇宙であって Π\PiΠ ではないので、型が Π\PiΠ である閉じた正規項は λ\lambdaλ に限られます。よって n=λ(P:Sort 0). sn = \tLam{P}{\Sort{0}}{s}n=λ(P:Sort0).s と書け、P:Sort 0⊢s:PP : \Sort{0} \vdash s : PP:Sort0⊢s:P かつ sss は正規です。では sss は何でありうるでしょうか。宇宙、Π\PiΠ、λ\lambdaλ なら、その型は宇宙か Π\PiΠ であって、変数 PPP ではありません。中立項ならスコープ内の変数から始まるはずですが、そのような変数は PPP 自身しかありません。その型は Sort 0\Sort{0}Sort0 で PPP ではないので sss が PPP そのものであることはなく、関数型でもないので PPP に何かを適用することもできません。結局、どの場合もありえないことがわかります。

付録 D では、この場合分けが暗に使っている型付けと変換の標準的な事実（生成（generation）、合流性、代入）も含めて、論証を丁寧にたどります。

直観的に言うとこうなります。Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P を証明するには、名前 PPP のほかに何の手がかりもない状態で、任意の命題 PPP の証明を作らなければなりません。正規形で考えると、この「手がかりがない」が文字どおりの意味になります。正規な証明は何かを生み出す計算を内側に隠せないので、スコープ内にあるものから直接組み立てるしかありませんが、スコープ内に型 PPP を持つものはありません。そして強正規化は、どんな証明もこの裏表のない形に直せることを保証します。

帰納型がある場合

第 II 部の ι 規則は互いに重ならず、β とも重ならないので、簡約の合流性は保たれます。型保存性、強正規化、整合性は Calculus of Inductive Constructions について成り立つことが知られており [Werner 1994]、帰納型を加えた本書の体系はその小さな断片にあたります。ただし、上の短い整合性の論証はそのままでは通用しません。正規形の中に、nnn が変数であるような Nat.rec0  M  z  s  n\NatRec{0}\;M\;z\;s\;nNat.rec0​Mzsn など、行き詰まった再帰子の適用が現れるからです。この場合の整合性は、定数を頭部に持つ中立項まで含めて正規形をより注意深く解析することで、強正規化から導かれます。

第 8 章の受理条件は、どれもこの解析が破綻しうる経路を一つずつふさいでいます。正値性がなければ ι 簡約がループしうるので、強正規化が失われます。宇宙条件がなければ型が自分自身の宇宙を含みうるので、第 13 章のパラドックスが戻ってきます。命題に対する消去の制限がなければ、証明無関係性（proof irrelevance。Lean はこれを仮定しています）が反証されてしまいます。

Lean の完全な理論は、定義的な証明無関係性、宇宙多相、商型、一般の入れ子帰納型と相互帰納型を備えているため、そのメタ理論はより微妙になります。詳しくは Carneiro の学位論文 [Carneiro 2019] を参照してください。それでも中心にある構造、つまり強正規化と正規形の解析の組み合わせは変わりません。

Lean のカーネルも本書のカーネルと同じく、これらの定理を証明してはおらず、成り立つものとして扱っています。定理はコードについてではなく型システムについて数学的に証明し、コードにはその型システムを忠実に実装することを求める、という分担です。本書ではカーネルを小さく保ち、規則を図 3.1、第 8 章、アルゴリズム 12.1 にまとめているので、読者自身も実装が規則に従っているかを確かめられます。

演習

Type:Type\mathsf{Type} : \mathsf{Type}Type:Type を持つカーネルでは、第 13 章の議論によると四つの性質のうちどれが失われるでしょうか。

解答

強正規化（Hurkens の項は正規形を持ちません）と整合性（その項は型 Π(P:Type). P\tPi{P}{\mathsf{Type}}{P}Π(P:Type).P を持ちます）です。型の一意性と型保存性は規則の形に関する性質で、宇宙の構造には左右されないので、依然として成り立ちます。

整合性の論証では、Π\PiΠ 型を持つ閉じた正規項は λ\lambdaλ に限られるとしました。定数を加えるとこれが成り立たなくなるのはなぜでしょうか。また、代わりに何が必要になるでしょうか。

解答

succ\sucsucc や Nat.rec0\NatRec{0}Nat.rec0​ のような定数は閉じていて、正規項の頭部にもなれます。そのため Π\PiΠ 型を持つ閉じた正規項は、たとえば succ\sucsucc そのものや、行き詰まった再帰子の適用であってもかまいません。そこで解析では定数を頭部とする中立項も考え、スキーマが構成子と再帰子に割り当てる具体的な型を使って、どれも型 Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P を持ちえないことを示す必要があります。Werner の学位論文は、Calculus of Inductive Constructions についてこれを行っています。

覚えておくこと

  • 型の一意性と型の正しさによって Infer\InferInfer が矛盾なく定まり、型保存性によって正規化で等しさを判定してよいことが保証され、強正規化によってすべてが停止します。
  • 整合性は、強正規化と、正規形の場合分け（スコープ内のどれも任意の PPP を証明できない）から導かれます。
  • 受理条件が成り立つかぎり、帰納型を加えても四つの性質はすべて保たれます。各条件は、それぞれ特定の破綻を防いでいます。
  • カーネルはこれらの定理を証明せずに仮定します。カーネルの仕事は、定理が対象とする体系を忠実に、読みやすく実装することです。

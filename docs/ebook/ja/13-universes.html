Type は型ではない

すべての宇宙を、自分自身を含む単一の宇宙 Type\mathsf{Type}Type で置き換えたとしよう。

⊢Γ;okΓ⊢Type:TypeΓ⊢A:TypeΓ,x:A⊢B:TypeΓ⊢Π(x:A). B:Type\dfrac{\ctxok{\Gamma}}{\Gamma \vdash \mathsf{Type} : \mathsf{Type}} \qquad \dfrac{\Gamma \vdash A : \mathsf{Type} \qquad \Gamma, x : A \vdash B : \mathsf{Type}}{\Gamma \vdash \tPi{x}{A}{B} : \mathsf{Type}}Γ⊢Type:Type⊢Γ;ok​Γ⊢Π(x:A).B:TypeΓ⊢A:TypeΓ,x:A⊢B:Type​

型理論には x∉xx \notin xx∈/x のような所属判定がないので、ラッセルの議論はそのままでは移らない。Girard は代わりに、すべての整列順序の集まりに関する Burali-Forti の関連するパラドックスを翻案し [Girard 1972]、Hurkens が得られた項を簡略化した [Hurkens 1995]。結果は

⊢tH:Π(P:Type). P,\vdash t_{\mathrm{H}} : \tPi{P}{\mathsf{Type}}{P},⊢tH​:Π(P:Type).P,

を満たす閉じた項 tHt_{\mathrm{H}}tH​ であり、体系は不整合である。⊥\bot⊥ には証明がないのに ⊥∗\bot^\ast⊥∗ には項があり、これらの規則の上に作られたカーネルはあらゆる文の証明を受け入れてしまう。本質的な材料は、Type\mathsf{Type}Type 全体を量化しながら Type\mathsf{Type}Type の要素でもある型 UUU である。これにより UUU は自身の二重冪集合の複製を含むことができる。集合には決してできないことである。付録 C では tHt_{\mathrm{H}}tH​ を完全な形で示し、その仕組みを説明し、カーネルの一行を変えるだけでこの結果を再現する方法を示す。

被害はアルゴリズムにも及ぶ。主語簡約は依然として成り立つので、もし tHt_{\mathrm{H}}tH​ に正規形があれば、それは型 Π(p:Type). p\tPi{p}{\mathsf{Type}}{p}Π(p:Type).p の正規な閉じた項になる。付録 D の整合性の証明のうち正規な項を分析する部分は強正規化を使っておらず、Type:Type\mathsf{Type} : \mathsf{Type}Type:Type にもそのまま移る。それが示すのは、そのような正規な項は存在しないということだ。したがって tHt_{\mathrm{H}}tH​ には正規形がなく、強正規化は破れ、Normalize\NormalizeNormalize はこの項に対して永遠に走り続ける。Type:Type\mathsf{Type} : \mathsf{Type}Type:Type を持つカーネルは不健全であるだけでなく、入力によっては停止しない。

Martin-Löf の 1971 年の最初の型理論はこの規則を持っており、翌年、それに対して Girard のパラドックスが発見された。それ以来、すべての依存型理論は、宇宙の階層か、自己言及を断ち切る何らかの別の仕掛けを備えている。このパラドックスは珍奇な話ではない。自分自身を含む宇宙は自明な設計であり、その自明な設計が間違っているのである。

最下層が非述語的な階層

第二の答えは、Sort 0\Sort{0}Sort0 はより大きな宇宙に住み、その宇宙はさらに大きな宇宙に住む、というものである。

⊢Γ;okΓ⊢Sort u:Sort (u+1);(T-Sort)soSort 0:Sort 1:Sort 2:⋯ .\dfrac{\ctxok{\Gamma}}{\Gamma \vdash \Sort{u} : \Sort{(u+1)}}\rulename{T-Sort} \qquad\text{so}\qquad \Sort{0} : \Sort{1} : \Sort{2} : \cdots.Γ⊢Sortu:Sort(u+1)⊢Γ;ok​;(T-Sort)soSort0:Sort1:Sort2:⋯.

imax\imaximax の場合分けにより、Π\PiΠ 型は本体が命題のとき非述語的になり、それ以外のとき述語的になる。下で AAA と BBB の宇宙を選び、Π\PiΠ 型がどこに落ち着くかを見てほしい。

命題は非述語的である。 本体 BBB が命題なら（v=0v = 0v=0）、何を量化していようと Π\PiΠ 全体が命題になる。特に (∀P. φ)∗=Π(P:Sort 0). φ∗(\forall P.\,\varphi)^\ast = \tPi{P}{\Sort{0}}{\varphi^\ast}(∀P.φ)∗=Π(P:Sort0).φ∗ は、Sort 0\Sort{0}Sort0 全体を量化しているにもかかわらず Sort 0\Sort{0}Sort0 に属する。自分自身を量化する型を含む宇宙を非述語的（impredicative）と呼ぶ。翻訳された式はすべて Sort 0\Sort{0}Sort0 に属するので、∀\forall∀ 除去の前提 ψ∗:Sort 0\psi^\ast : \Sort{0}ψ∗:Sort0 は常に成り立ち、全称文は任意の命題で、自分自身でさえも、具体化できる。たとえば id=λ(P:Sort 0). λ(h:P). h\mathit{id} = \tLam{P}{\Sort{0}}{\tLam{h}{P}{h}}id=λ(P:Sort0).λ(h:P).h とすると、

型は述語的である。 本体が命題でなければ（v≥1v \ge 1v≥1）、Π\PiΠ は二つの宇宙のうち大きいほうに属する。Sort u\Sort{u}Sortu を量化する型は Sort (max⁡(u+1,v))\Sort{(\max(u+1, v))}Sort(max(u+1,v)) に属し、これは決して Sort u\Sort{u}Sortu にはならない。

この性質を述語性（predicativity）と呼ぶ。たとえば型上の恒等関数 λ(A:Sort 1). λ(a:A). a\tLam{A}{\Sort{1}}{\tLam{a}{A}{a}}λ(A:Sort1).λ(a:A).a の型は Π(A:Sort 1). A→A\tPi{A}{\Sort{1}}{A \to A}Π(A:Sort1).A→A で、これは Sort 2\Sort{2}Sort2 に属するので、自分自身の型には適用できない。Sort 2\Sort{2}Sort2 での複製なら適用できる。各レベルはその下のレベルを含み、実際には数レベルあれば足りる。より高いレベルが現れるのは、すべての小さい圏の圏のような、大きな集まりを量化するときである。

なぜ安全なのか。 非述語性は前節が警告した自己言及に似ているが、閉じ込められている。Sort 0\Sort{0}Sort0 は Sort 0\Sort{0}Sort0 を量化する型を含むが、Sort 0\Sort{0}Sort0 は自分自身の要素ではない。Coquand は、最下層に非述語的な宇宙が一つあっても整合的であることを示した [Coquand 1988]。一方、二つのレベルが非述語的になると、すでに Girard のパラドックスが導出できる [Hurkens 1995]。これらの規則のもとで体系は整合的かつ強正規化的である（第 14 章）。

なぜ命題は非述語的でよくて、型はそうではないのか。命題の証明は、プログラムが取り出せるようなデータを一切持たないからだ（第 8 章の消去制限が強制するのがこれである）。命題を定義するためにすべての命題を量化するのは、すべての集合に言及する性質によって集合を定義するのに似ている。結果がそれ自身、量化子の動く範囲にある対象であって、中身を調べられるなら危険だが、仮定として使うことしかできないなら無害である。パラドックスは自分が作ったものを調べる必要がある。命題は調べられない。

Lean との比較

Lean [de Moura and Ullrich 2021] では、Sort 0\Sort{0}Sort0 が Prop、Sort (u+1)\Sort{(u+1)}Sort(u+1) が Type u であり、Π\PiΠ 型には上と同じく imax\imaximax で宇宙が割り当てられる。違いは二つ残る。

第一に、Lean の Prop には定義的証明無関係性（definitional proof irrelevance）がある。同じ命題の任意の二つの証明は定義的に等しい。本書の変換は証明を同一視しない。これを加えると変換が型に依存するようになり、第 12 章 の単純な「正規化して比較する」検査では足りなくなる。

第二に、Lean には宇宙多相（universe polymorphism）があり、定義をすべてのレベル uuu について一度に述べられる。そのため imax\imaximax はレベル変数に対しても重要になり、imax(u,v)≤w\imax(u, v) \le wimax(u,v)≤w のような制約が記号的に解かれる。本書の体系では、すべてのレベルは具体的な数である。

覚えておくこと

  • Sort 0\Sort{0}Sort0 には型が必要である。命題変数が λ\lambdaλ と Π\PiΠ に束縛されるからだ。
  • 自分自身を含む宇宙は不整合であり（Girard、Hurkens）、正規化も壊す。

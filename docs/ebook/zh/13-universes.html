第 13 章

宇宙：为什么是 Sort u？

第 4 章说明了类型规则实现了一种逻辑，而只有当这个系统一致时它才可以接受。本章要回答一个从第 2 章起就一直搁置的问题：Sort 0\Sort{0}Sort0 的类型是什么？最简单的答案是一个包含自身的单一宇宙，它会使系统不一致。Lean 的答案是一个层级 Sort 0:Sort 1:Sort 2:⋯\Sort{0} : \Sort{1} : \Sort{2} : \cdotsSort0:Sort1:Sort2:⋯，底层宇宙是非谓词的，这样就不会不一致。本章还会顺带解释 T-Pi 中唯一看起来古怪的部分：函数 imax\imaximax。

Sort 0 的类型是什么？

命题变量在类型论中以假设 P:Sort 0P : \Sort{0}P:Sort0 的形式出现，它可以出现在两个地方：在上下文中，如下面左边的判断；或被 λ\lambdaλ 或 Π\PiΠ 绑定，如右边的判断：

P:Sort 0⊢λ(h:P). h:P→Pversus⊢λ(P:Sort 0). λ(h:P). h:Π(P:Sort 0). P→P.P : \Sort{0} \vdash \tLam{h}{P}{h} : P \to P \qquad\text{versus}\qquad \vdash \tLam{P}{\Sort{0}}{\tLam{h}{P}{h}} : \tPi{P}{\Sort{0}}{P \to P}.P:Sort0⊢λ(h:P).h:P→Pversus⊢λ(P:Sort0).λ(h:P).h:Π(P:Sort0).P→P.

左边的判断对一个由外部提供的固定 PPP 证明了 P→PP \to PP→P，而右边的是一个封闭项，它对每一个 PPP 都证明了这一点，并且之后可以应用到任何具体的命题上；图 4.1 中的 ∀\forall∀ 各行需要的正是这个。

两种形式都要求 Sort 0\Sort{0}Sort0 是一个类型。把 P:Sort 0P : \Sort{0}P:Sort0 加入上下文的 C-Ext，以及绑定 P:Sort 0P : \Sort{0}P:Sort0 的 T-Lam 和 T-Pi，都对新变量的类型 AAA 有前提 Γ⊢A:Sort u\Gamma \vdash A : \Sort{u}Γ⊢A:Sortu。当 A=Sort 0A = \Sort{0}A=Sort0 时，这个前提就是对某个 uuu 有 Γ⊢Sort 0:Sort u\Gamma \vdash \Sort{0} : \Sort{u}Γ⊢Sort0:Sortu：命题宇宙本身必须有一个类型。问题是，是哪一个。

Type 不是 Type

假设我们把所有宇宙换成一个包含自身的单一宇宙 Type\mathsf{Type}Type：

⊢Γ;okΓ⊢Type:TypeΓ⊢A:TypeΓ,x:A⊢B:TypeΓ⊢Π(x:A). B:Type\dfrac{\ctxok{\Gamma}}{\Gamma \vdash \mathsf{Type} : \mathsf{Type}} \qquad \dfrac{\Gamma \vdash A : \mathsf{Type} \qquad \Gamma, x : A \vdash B : \mathsf{Type}}{\Gamma \vdash \tPi{x}{A}{B} : \mathsf{Type}}Γ⊢Type:Type⊢Γ;ok​Γ⊢Π(x:A).B:TypeΓ⊢A:TypeΓ,x:A⊢B:Type​

把 ∀P. φ\forall P.\,\varphi∀P.φ 翻译为 Π(P:Type). φ∗\tPi{P}{\mathsf{Type}}{\varphi^\ast}Π(P:Type).φ∗。于是 PPP 的取值范围是一个包含 Type\mathsf{Type}Type 自身以及由它构造出的每个类型的集合体。这样的集合体是“所有集合的集合”在类型论中的对应物，而朴素集合论已经表明，这类集合体会导出矛盾。最著名的例子是罗素悖论（Russell's paradox）：令 R={ x∣x∉x }R = \{\, x \mid x \notin x \,\}R={x∣x∈/x}，则 R∈RR \in RR∈R 和 R∉RR \notin RR∈/R 都导出矛盾。

类型论没有 x∉xx \notin xx∈/x 这样的成员关系测试，所以罗素的论证不能逐字搬过来。Girard 改而改编了一个相关的悖论，即 Burali-Forti 关于所有良序的集合体的悖论 [Girard 1972]，Hurkens 随后简化了由此得到的项 [Hurkens 1995]。结果是一个封闭项 tHt_{\mathrm{H}}tH​，满足

⊢tH:Π(P:Type). P,\vdash t_{\mathrm{H}} : \tPi{P}{\mathsf{Type}}{P},⊢tH​:Π(P:Type).P,

因此系统不一致：⊥\bot⊥ 没有证明，⊥∗\bot^\ast⊥∗ 却有一个项，于是建立在这些规则之上的内核会接受每个陈述的证明。关键的要素是一个类型 UUU，它对整个 Type\mathsf{Type}Type 进行量化，同时又是 Type\mathsf{Type}Type 的成员，这使得 UUU 可以包含自身二重幂集的一个副本，而这是任何集合都做不到的。附录 C 完整给出 tHt_{\mathrm{H}}tH​，解释它的工作原理，并展示如何只改动内核的一行代码来重现这个结果。

损害同样波及算法：类型保持性仍然成立，所以如果 tHt_{\mathrm{H}}tH​ 有范式，它就会是类型为 Π(p:Type). p\tPi{p}{\mathsf{Type}}{p}Π(p:Type).p 的一个处于范式的封闭项。附录 D 中一致性证明里分析范式项的那一部分不用强规范化，可以搬到 Type:Type\mathsf{Type} : \mathsf{Type}Type:Type 上；它表明这样的范式项不存在。因此 tHt_{\mathrm{H}}tH​ 没有范式，强规范化失效，Normalize\NormalizeNormalize 在它上面永远运行下去。带有 Type:Type\mathsf{Type} : \mathsf{Type}Type:Type 的内核不仅不可靠，而且在某些输入上不终止。

Martin-Löf 1971 年的第一个类型论就有这条规则，第二年 Girard 悖论就针对它被发现了。此后的每一种依赖类型论都要么有一个宇宙层级，要么有某种别的装置来打破自指。这个悖论不是猎奇：自含的宇宙是显而易见的设计，而显而易见的设计是错的。

底层非谓词的层级

第二种答案是：Sort 0\Sort{0}Sort0 住在一个更大的宇宙里，后者又住在一个更大的宇宙里：

⊢Γ;okΓ⊢Sort u:Sort (u+1);(T-Sort)soSort 0:Sort 1:Sort 2:⋯ .\dfrac{\ctxok{\Gamma}}{\Gamma \vdash \Sort{u} : \Sort{(u+1)}}\rulename{T-Sort} \qquad\text{so}\qquad \Sort{0} : \Sort{1} : \Sort{2} : \cdots.Γ⊢Sortu:Sort(u+1)⊢Γ;ok​;(T-Sort)soSort0:Sort1:Sort2:⋯.

没有宇宙包含自身。Π\PiΠ 类型从一个宇宙取参数，在另一个宇宙中返回类型，所以 T-Pi 还必须说明 Π\PiΠ 类型本身属于哪个宇宙；Lean 的答案使用函数 imax\imaximax：

Γ⊢A:Sort uΓ,x:A⊢B:Sort vΓ⊢Π(x:A). B:Sort imax(u,v);(T-Pi)imax(u,v)={0if v=0,max⁡(u,v)otherwise.\dfrac{\Gamma \vdash A : \Sort{u} \qquad \Gamma, x : A \vdash B : \Sort{v}}{\Gamma \vdash \tPi{x}{A}{B} : \Sort{\imax(u, v)}}\rulename{T-Pi} \qquad \imax(u, v) = \begin{cases} 0 & \text{if } v = 0, \\ \max(u, v) & \text{otherwise.} \end{cases}Γ⊢Π(x:A).B:Sortimax(u,v)Γ⊢A:SortuΓ,x:A⊢B:Sortv​;(T-Pi)imax(u,v)={0max(u,v)​if v=0,otherwise.​

imax\imaximax 中的分情形使得 Π\PiΠ 类型在函数体是命题时是非谓词的（impredicative），否则是谓词的（predicative）。在下面选择 AAA 和 BBB 的宇宙，观察 Π\PiΠ 类型落在哪里。

命题是非谓词的。 如果函数体 BBB 是命题（v=0v = 0v=0），那么无论它对什么进行量化，整个 Π\PiΠ 都是命题。特别地，(∀P. φ)∗=Π(P:Sort 0). φ∗(\forall P.\,\varphi)^\ast = \tPi{P}{\Sort{0}}{\varphi^\ast}(∀P.φ)∗=Π(P:Sort0).φ∗ 属于 Sort 0\Sort{0}Sort0，尽管它对整个 Sort 0\Sort{0}Sort0 进行量化。包含对自身进行量化的类型的宇宙称为非谓词的（impredicative）。因为每个翻译后的公式都在 Sort 0\Sort{0}Sort0 中，∀\forall∀-elim 的前提 ψ∗:Sort 0\psi^\ast : \Sort{0}ψ∗:Sort0 总是成立，所以全称陈述可以用任何命题实例化，甚至用它自己。例如，令 id=λ(P:Sort 0). λ(h:P). h\mathit{id} = \tLam{P}{\Sort{0}}{\tLam{h}{P}{h}}id=λ(P:Sort0).λ(h:P).h，则

id:Π(P:Sort 0). P→PandΠ(P:Sort 0). P→P:Sort 0,\mathit{id} : \tPi{P}{\Sort{0}}{P \to P} \qquad\text{and}\qquad \tPi{P}{\Sort{0}}{P \to P} : \Sort{0},id:Π(P:Sort0).P→PandΠ(P:Sort0).P→P:Sort0,

所以 id  (Π(P:Sort 0). P→P)  id\mathit{id}\;(\tPi{P}{\Sort{0}}{P \to P})\;\mathit{id}id(Π(P:Sort0).P→P)id 是良类型的，其类型为 Π(P:Sort 0). P→P\tPi{P}{\Sort{0}}{P \to P}Π(P:Sort0).P→P。同一情形也使 ∀n:Nat, n+0=n\forall n : \Nat,\, n + 0 = n∀n:Nat,n+0=n 成为命题，尽管 Nat\NatNat 住在 Sort 1\Sort{1}Sort1 中；第 7 章的归纳正是依赖于此。

# “每个命题都蕴涵自身”本身就是一个命题，
# 所以它可以用自己来实例化。
def id : forall (P : Sort 0), P -> P := fun (P : Sort 0) => fun (h : P) => h
def self : forall (P : Sort 0), P -> P := id (forall (P : Sort 0), P -> P) id

# 高一层的类似陈述却不是自己的实例：
# forall (A : Sort 1), A -> A 住在 Sort 2 中，而不是 Sort 1。
def idT : forall (A : Sort 1), A -> A := fun (A : Sort 1) => fun (a : A) => a

类型是谓词的。 如果函数体不是命题（v≥1v \ge 1v≥1），Π\PiΠ 就住在两个宇宙中较大的那个里。于是，对 Sort u\Sort{u}Sortu 进行量化的类型住在 Sort (max⁡(u+1,v))\Sort{(\max(u+1, v))}Sort(max(u+1,v)) 中，它永远不会是 Sort u\Sort{u}Sortu：

Γ⊢Sort u:Sort (u+1);(T-Sort)Γ,x:Sort u⊢B:Sort vΓ⊢Π(x:Sort u). B:Sort (max⁡(u+1,v));(T-Pi)\dfrac{ \dfrac{}{\Gamma \vdash \Sort{u} : \Sort{(u+1)}}\rulename{T-Sort} \qquad \Gamma, x : \Sort{u} \vdash B : \Sort{v} }{\Gamma \vdash \tPi{x}{\Sort{u}}{B} : \Sort{(\max(u+1, v))}}\rulename{T-Pi}Γ⊢Π(x:Sortu).B:Sort(max(u+1,v))Γ⊢Sortu:Sort(u+1)​;(T-Sort)Γ,x:Sortu⊢B:Sortv​;(T-Pi)

这个性质称为谓词性（predicativity）。例如，类型上的恒等函数 λ(A:Sort 1). λ(a:A). a\tLam{A}{\Sort{1}}{\tLam{a}{A}{a}}λ(A:Sort1).λ(a:A).a 的类型是 Π(A:Sort 1). A→A\tPi{A}{\Sort{1}}{A \to A}Π(A:Sort1).A→A，它住在 Sort 2\Sort{2}Sort2 中，所以不能应用到自己的类型上；而 Sort 2\Sort{2}Sort2 处的一个副本可以。每一层都容纳它下面的那一层；实践中几层就够了，更高的层级只在对大的集合体进行量化时出现，比如所有小范畴构成的范畴。

为什么这是安全的。 非谓词性看起来像上一节所警告的自指，但它被限制住了：Sort 0\Sort{0}Sort0 包含对 Sort 0\Sort{0}Sort0 进行量化的类型，但 Sort 0\Sort{0}Sort0 不是自身的成员。Coquand 证明了底层的一个非谓词宇宙是一致的 [Coquand 1988]，而一旦有两层是非谓词的，Girard 悖论就已经可以推导出来 [Hurkens 1995]。采用这些规则，系统是一致的且强规范化的（第 14 章）。

为什么命题可以是非谓词的，而类型不可以？命题的证明不携带程序可提取的数据，第 8 章的消去限制也确保了这一点。对所有命题量化后定义一个命题，类似于用涉及所有集合的性质定义集合：如果结果也在量词的范围内，而且可以检查其内容，就会出问题；若只能把它当作假设使用，同样的问题便不会出现。悖论需要检查它构造出的对象，但命题的证明不允许这种操作。

与 Lean 的比较

在 Lean [de Moura and Ullrich 2021] 中，Sort 0\Sort{0}Sort0 是 Prop，Sort (u+1)\Sort{(u+1)}Sort(u+1) 是 Type u，Π\PiΠ 类型的宇宙按上面的 imax\imaximax 指派。还有两处差别。

第一，Lean 的 Prop 具有定义性证明无关性（definitional proof irrelevance）：同一个命题的任意两个证明在定义上相等。我们的转换不把证明视为相同；加上这一点会让转换依赖于类型，于是第 12 章那种简单的“规范化后比较”检查就不再够用。

第二，Lean 有宇宙多态（universe polymorphism），所以定义可以对所有层级 uuu 一次性陈述，imax\imaximax 此时也要对层级变量起作用，诸如 imax(u,v)≤w\imax(u, v) \le wimax(u,v)≤w 这样的约束要符号化求解，而在我们的系统中，每个层级都是一个具体的数。

本章的全部内容就是 src/typecheck.rs 中 infer 的两行：Sort(u) 情形返回 Sort(u + 1)；Pi 情形在函数体的层级为 0 时返回 Sort(0)，否则返回最大值。附录 C 展示了把第一行改成返回 Sort(u) 后，内核就会接受 Hurkens 的项。

说明演练场中的 selfT 定义为什么被拒绝，指出所涉及的规则和两个宇宙。

解答

idT 期望一个参数 A:Sort 1A : \Sort{1}A:Sort1，而实际提供的参数是 Π(A:Sort 1). A→A\tPi{A}{\Sort{1}}{A \to A}Π(A:Sort1).A→A，按 T-Pi 它的宇宙是 max⁡(2,1)=2\max(2, 1) = 2max(2,1)=2，于是 Check\CheckCheck 比较 Sort 2\Sort{2}Sort2 与 Sort 1\Sort{1}Sort1 并失败：内核在该应用处报告类型不匹配。这就是谓词性：对 Sort 1\Sort{1}Sort1 进行量化的类型不在 Sort 1\Sort{1}Sort1 中。

要点回顾

  • Sort 0\Sort{0}Sort0 需要一个类型，因为命题变量会被 λ\lambdaλ 和 Π\PiΠ 绑定。
  • 包含自身的宇宙是不一致的（Girard，Hurkens），并且破坏规范化。
  • 层级 Sort u:Sort (u+1)\Sort{u} : \Sort{(u+1)}Sortu:Sort(u+1) 避免了自含；imax\imaximax 使命题成为非谓词的，其余一切成为谓词的。
  • 底层的一个非谓词宇宙是安全的，两个则不然。Lean 在同样的设计之上又加了证明无关性和宇宙多态。

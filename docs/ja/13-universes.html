Sort 0 の型は何か

Type を型にすると矛盾する

まず、すべての宇宙を、自分自身を含む単一の宇宙 Type\mathsf{Type}Type で置き換えてみましょう。

⊢Γ;okΓ⊢Type:TypeΓ⊢A:TypeΓ,x:A⊢B:TypeΓ⊢Π(x:A). B:Type\dfrac{\ctxok{\Gamma}}{\Gamma \vdash \mathsf{Type} : \mathsf{Type}} \qquad \dfrac{\Gamma \vdash A : \mathsf{Type} \qquad \Gamma, x : A \vdash B : \mathsf{Type}}{\Gamma \vdash \tPi{x}{A}{B} : \mathsf{Type}}Γ⊢Type:Type⊢Γ;ok​Γ⊢Π(x:A).B:TypeΓ⊢A:TypeΓ,x:A⊢B:Type​

∀P. φ\forall P.\,\varphi∀P.φ を Π(P:Type). φ∗\tPi{P}{\mathsf{Type}}{\varphi^\ast}Π(P:Type).φ∗ と翻訳すると、PPP は Type\mathsf{Type}Type 自身とそこから作られるあらゆる型を含む集まりを動きます。これは型理論版の「すべての集合の集合」であり、素朴集合論ではこの種の集まりが矛盾を導くことが知られています。最も有名なのがラッセルのパラドックスで、R={ x∣x∉x }R = \{\, x \mid x \notin x \,\}R={x∣x∈/x} とおくと、R∈RR \in RR∈R と R∉RR \notin RR∈/R のどちらを仮定しても矛盾が出ます。

型理論には x∉xx \notin xx∈/x のような所属判定がないので、ラッセルの議論はそのままでは使えません。そこで Girard は、すべての整列順序の集まりにまつわる Burali-Forti のパラドックスを型理論に持ち込み [Girard 1972]、Hurkens がその項を簡略化しました [Hurkens 1995]。得られるのは

⊢tH:Π(P:Type). P,\vdash t_{\mathrm{H}} : \tPi{P}{\mathsf{Type}}{P},⊢tH​:Π(P:Type).P,

を満たす閉じた項 tHt_{\mathrm{H}}tH​ で、体系は不整合になります。⊥\bot⊥ には証明がないはずなのに ⊥∗\bot^\ast⊥∗ には項があるので、これらの規則の上に作ったカーネルはどんな文の証明でも受け入れてしまいます。鍵になるのは、Type\mathsf{Type}Type 全体を量化しながら、それ自身も Type\mathsf{Type}Type の要素である型 UUU です。このおかげで UUU は自身の二重冪集合の複製を含めますが、集合では決してこうはなりません。付録 C では tHt_{\mathrm{H}}tH​ の全体を示して仕組みを説明し、カーネルを一行変えるだけでこの結果を再現する方法も紹介します。

被害はアルゴリズムにも及びます。型保存性は依然として成り立つので、もし tHt_{\mathrm{H}}tH​ に正規形があれば、それは型 Π(p:Type). p\tPi{p}{\mathsf{Type}}{p}Π(p:Type).p をもつ正規な閉じた項になります。ところが 付録 D の整合性の証明のうち、正規な項を分析する部分は強正規化を使っていないので Type:Type\mathsf{Type} : \mathsf{Type}Type:Type にもそのまま当てはまり、そのような正規な項は存在しないことがわかります。したがって tHt_{\mathrm{H}}tH​ には正規形がなく、強正規化は破れ、Normalize\NormalizeNormalize はこの項に対して永遠に走り続けます。Type:Type\mathsf{Type} : \mathsf{Type}Type:Type をもつカーネルは不健全なうえに、入力によっては停止すらしません。

Martin-Löf が 1971 年に発表した最初の型理論はこの規則をもっており、翌年、Girard がそこにパラドックスを見つけました。それ以来、どの依存型理論も、宇宙の階層か、自己言及を断ち切る別の仕掛けを備えています。これは珍しい落とし穴の話ではありません。自分自身を含む宇宙は誰もが最初に思いつく自明な設計であり、その自明な設計が間違っているのです。

最下層が非述語的な階層

もう一つの答えは、Sort 0\Sort{0}Sort0 をより大きな宇宙に住まわせ、その宇宙をさらに大きな宇宙に住まわせる、というものです。

⊢Γ;okΓ⊢Sort u:Sort (u+1);(T-Sort)soSort 0:Sort 1:Sort 2:⋯ .\dfrac{\ctxok{\Gamma}}{\Gamma \vdash \Sort{u} : \Sort{(u+1)}}\rulename{T-Sort} \qquad\text{so}\qquad \Sort{0} : \Sort{1} : \Sort{2} : \cdots.Γ⊢Sortu:Sort(u+1)⊢Γ;ok​;(T-Sort)soSort0:Sort1:Sort2:⋯.

imax\imaximax の場合分けによって、Π\PiΠ 型は本体が命題のときに非述語的に、それ以外のときに述語的になります。下で AAA と BBB の宇宙を選び、Π\PiΠ 型がどの宇宙に入るかを確かめてください。

命題は非述語的である。 本体 BBB が命題なら（v=0v = 0v=0）、何を量化していても Π\PiΠ 全体が命題になります。特に (∀P. φ)∗=Π(P:Sort 0). φ∗(\forall P.\,\varphi)^\ast = \tPi{P}{\Sort{0}}{\varphi^\ast}(∀P.φ)∗=Π(P:Sort0).φ∗ は、Sort 0\Sort{0}Sort0 全体を量化しているにもかかわらず Sort 0\Sort{0}Sort0 に属します。自分自身を量化する型を含む宇宙を非述語的（impredicative）と呼びます。翻訳された式はすべて Sort 0\Sort{0}Sort0 に属するので、∀\forall∀ 除去の前提 ψ∗:Sort 0\psi^\ast : \Sort{0}ψ∗:Sort0 は常に成り立ち、全称文はどんな命題でも、自分自身でさえも、具体化できます。たとえば id=λ(P:Sort 0). λ(h:P). h\mathit{id} = \tLam{P}{\Sort{0}}{\tLam{h}{P}{h}}id=λ(P:Sort0).λ(h:P).h とすると、

id:Π(P:Sort 0). P→PandΠ(P:Sort 0). P→P:Sort 0,\mathit{id} : \tPi{P}{\Sort{0}}{P \to P} \qquad\text{and}\qquad \tPi{P}{\Sort{0}}{P \to P} : \Sort{0},id:Π(P:Sort0).P→PandΠ(P:Sort0).P→P:Sort0,

# 自分自身で具体化できる。
def id : forall (P : Sort 0), P -> P := fun (P : Sort 0) => fun (h : P) => h

型は述語的である。 本体が命題でなければ（v≥1v \ge 1v≥1）、Π\PiΠ は二つの宇宙のうち大きいほうに属します。したがって Sort u\Sort{u}Sortu を量化する型は Sort (max⁡(u+1,v))\Sort{(\max(u+1, v))}Sort(max(u+1,v)) に属し、Sort u\Sort{u}Sortu に入ることは決してありません。

Γ⊢Sort u:Sort (u+1);(T-Sort)Γ,x:Sort u⊢B:Sort vΓ⊢Π(x:Sort u). B:Sort (max⁡(u+1,v));(T-Pi)\dfrac{ \dfrac{}{\Gamma \vdash \Sort{u} : \Sort{(u+1)}}\rulename{T-Sort} \qquad \Gamma, x : \Sort{u} \vdash B : \Sort{v} }{\Gamma \vdash \tPi{x}{\Sort{u}}{B} : \Sort{(\max(u+1, v))}}\rulename{T-Pi}Γ⊢Π(x:Sortu).B:Sort(max(u+1,v))Γ⊢Sortu:Sort(u+1)​;(T-Sort)Γ,x:Sortu⊢B:Sortv​;(T-Pi)

この性質を述語性（predicativity）と呼びます。たとえば型上の恒等関数 λ(A:Sort 1). λ(a:A). a\tLam{A}{\Sort{1}}{\tLam{a}{A}{a}}λ(A:Sort1).λ(a:A).a の型は Π(A:Sort 1). A→A\tPi{A}{\Sort{1}}{A \to A}Π(A:Sort1).A→A で、これは Sort 2\Sort{2}Sort2 に属します。そのため恒等関数を自分自身の型に適用できませんが、Sort 2\Sort{2}Sort2 版の恒等関数なら適用できます。各レベルはその下のレベルを含みます。実際には数レベルあれば足り、それより高いレベルが必要になるのは、すべての小さい圏の圏のような大きな集まりを量化するときくらいです。

なぜ安全なのでしょうか。 非述語性は前節で警告した自己言及に似ていますが、範囲が閉じ込められています。Sort 0\Sort{0}Sort0 は Sort 0\Sort{0}Sort0 を量化する型を含みますが、Sort 0\Sort{0}Sort0 自身はその要素ではありません。Coquand は、最下層に非述語的な宇宙が一つあっても整合的であることを示しました [Coquand 1988]。ところが非述語的なレベルが二つになると、それだけで Girard のパラドックスが導出できます [Hurkens 1995]。本章の規則のもとでは、体系は整合的かつ強正規化的です（第 14 章）。

なぜ命題は非述語的でよく、型はだめなのでしょうか。命題の証明には、プログラムが取り出せるデータがありません。第 8 章の消去制限も、この性質を守るためのものです。すべての命題を量化して命題を定義するのは、すべての集合に言及する性質で集合を定義するのに似ています。作ったものが量化の対象に含まれ、しかも中身を調べられるなら危険ですが、仮定として使うことしかできなければ同じ問題は起きません。パラドックスを起こすには作ったものを調べる操作が必要で、命題の証明ではそれができないのです。

Lean との比較

Lean [de Moura and Ullrich 2021] では Sort 0\Sort{0}Sort0 が Prop、Sort (u+1)\Sort{(u+1)}Sort(u+1) が Type u にあたり、Π\PiΠ 型の宇宙は本章と同じく imax\imaximax で決まります。違いは二つあります。

第一に、Lean の Prop には定義的証明無関係性（definitional proof irrelevance）があり、同じ命題の証明はどの二つも定義的に等しいとみなされます。本書の変換は証明を同一視しません。これを加えると変換が型に依存するようになり、第 12 章 の「正規化して比較する」という単純な検査では足りなくなります。

第二に、Lean には宇宙多相（universe polymorphism）があり、定義をすべてのレベル uuu についてまとめて書けます。そのため imax\imaximax はレベル変数に対しても意味をもち、imax(u,v)≤w\imax(u, v) \le wimax(u,v)≤w のような制約を記号的に解く必要が出てきます。本書の体系では、レベルはすべて具体的な数です。

覚えておくこと

  • 命題変数は λ\lambdaλ や Π\PiΠ で束縛されるので、Sort 0\Sort{0}Sort0 にも型が必要です。
  • 自分自身を含む宇宙は体系を不整合にし（Girard、Hurkens）、正規化も壊します。
  • 階層 Sort u:Sort (u+1)\Sort{u} : \Sort{(u+1)}Sortu:Sort(u+1) で自己包含を避け、imax\imaximax によって命題だけを非述語的に、それ以外はすべて述語的にします。

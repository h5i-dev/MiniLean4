第 9 章

相等也是归纳类型

要陈述 0+n=n0 + n = n0+n=n 这样的数论事实，就需要表达相等。虽然相等似乎需要内核内置专门的规则，它其实是按第 8 章的方法生成的归纳类型；利用它的递归子，可以把关于 aaa 的事实转化为关于 bbb 的事实。本章声明这个类型，说明它与定义相等的区别，并证明本书第一个实质性的定理。

声明

在 Lean 中，相等的声明是

inductive Eq {A : Sort u} (a : A) : A -> Prop where
  | refl : Eq a a

对 a,b:Aa, b : Aa,b:A，类型 Equ  A  a  b\Eq{u}\;A\;a\;bEqu​Aab 是“aaa 与 bbb 相等”这一命题；当 AAA 是 Nat\NatNat 时我们把它写作 a=ba = ba=b。用第 8 章的术语说，AAA 和 aaa 是参数，bbb 是索引：

Equ:Π(A:Sort u). A→A→Sort 0,reflu:Π(A:Sort u). Π(a:A). Equ  A  a  a.\Eq{u} : \tPi{A}{\Sort{u}}{A \to A \to \Sort{0}}, \qquad \refl{u} : \tPi{A}{\Sort{u}}{\tPi{a}{A}{\Eq{u}\;A\;a\;a}}.Equ​:Π(A:Sortu).A→A→Sort0,reflu​:Π(A:Sortu).Π(a:A).Equ​Aaa.

唯一的构造子 reflu\refl{u}reflu​ 没有字段，它的索引项是 aaa：它只能证明两边是同一个 aaa 的等式。所以 Eq\Eq{}Eq​ 像 Vec\mathsf{Vec}Vec 一样是归纳族，而不是单个类型。左边由参数固定；右边可变，而构造子把它钉在左边上。

为什么一个构造子就够了？因为这个声明并不定义两个东西何时相等；它说的是相等的证明可以如何构造，而唯一的方式就是观察到某物等于它自己。其余一切，如对称性、传递性和替换，都由递归子导出，递归子说的是一旦有了这样的证明，能用它做什么。

递归子：传输

非形式地说，Eq\Eq{}Eq​ 的递归子表示：若 a=ba = ba=b，则凡对 aaa 成立者对 bbb 也成立。 这是莱布尼茨原理，其最常见的形式是

Eq.ndrecu,v:Π(A:Sort u). Π(a:A). Π(M:A→Sort v). M  a→Π(b:A). Equ  A  a  b→M  b.\EqRec{u,v} : \tPi{A}{\Sort{u}}{\tPi{a}{A}{\tPi{M}{A \to \Sort{v}}{M\;a \to \tPi{b}{A}{\Eq{u}\;A\;a\;b \to M\;b}}}}.Eq.ndrecu,v​:Π(A:Sortu).Π(a:A).Π(M:A→Sortv).Ma→Π(b:A).Equ​Aab→Mb.

给定 AAA 的元素的一个性质 MMM、证据 m:M  am : M\;am:Ma 和 a=ba = ba=b 的证明 hhh，它返回 M  bM\;bMb 的证据，我们说它沿着 hhh 传输 mmm。它的计算规则说，沿着 refl\refl{}refl​ 传输什么也不做：

在 Lean 中，Eq 的类型参数是隐式的，在声明中写作 {A}，由繁饰器填入，所以用户写 Eq a b 或 a = b。我们的内核只看到完全显式的项，因此我们写出每一个参数；填入它们是内核之上那一层的工作。在脚本语言中，这些常量是 Eq、Eq.refl 以及依赖递归子 Eq.rec0 和 Eq.rec1；非依赖的 Eq.ndrec\EqRec{}Eq.ndrec​ 没有预先声明，但它只是一个两行的定义，见下面的演练场。由于没有宇宙多态，内核只在 A:Sort 1A : \Sort{1}A:Sort1 处声明一次 Eq，这覆盖了 Nat\NatNat 和每个用户声明的数据类型；证明之间的相等则不可用。

定义相等与命题相等

现在有了两种相等概念，区分它们是理解证明助手行为的关键。

  • 定义相等 ≡\conv≡ 由内核通过计算来判定。它是关于项的判断，不是类型；不涉及任何证明对象。
  • 命题相等 Eq\Eq{}Eq​ 是一个类型，它的证明是项，而找到一个证明可能需要真正的推理，例如归纳。

构造子 refl\refl{}refl​ 把二者联系起来：由 T-Conv，只要 a≡ba \conv ba≡b，就有 reflu  A  a:Equ  A  a  b\refl{u}\;A\;a : \Eq{u}\;A\;a\;breflu​Aa:Equ​Aab。所以每个定义相等都免费给出一个命题相等，但反之不成立，标准的例子是 n+0=nn + 0 = nn+0=n 和 0+n=n0 + n = n0+n=n 这两半。采用第 7 章 add\addadd 的定义，并记 sss 为它的步骤函数，

n+0  →δβ  Nat.rec1  (λ(_:Nat). Nat)  n  s  zero  →ι  n,n + 0 \;\to_{\delta\beta}\; \NatRec{1}\;(\tLam{\_}{\Nat}{\Nat})\;n\;s\;\zero \;\iotared\; n,n+0→δβ​Nat.rec1​(λ(_:Nat).Nat)nszero→ι​n,

所以 refl1  Nat  n:n+0=n\refl{1}\;\Nat\;n : n + 0 = nrefl1​Natn:n+0=n，Lean 用 rfl 证明它。相反，

是卡住的：nnn 是变量，而 ι 规则只在 zero\zerozero 和 succ\sucsucc 上触发。所以 0+n=n0 + n = n0+n=n 不能用 refl\refl{}refl​ 证明，需要归纳。

哪些等式由 rfl 成立，取决于函数是如何定义的，而不是它计算什么。对第二个参数递归的加法使 n+0=nn + 0 = nn+0=n 成为定义相等、0+n=n0 + n = n0+n=n 成为命题相等；对第一个参数递归则会把二者对调。Lean 用户经常遇到这种情况：rfl 能否关闭目标，取决于相关定义中递归的方向。

内核的变化

从命题逻辑走到带相等的算术，内核改动很少：Infer\InferInfer 增加了常量的情形，它在 Σ\SigmaΣ 中查找类型（T-Const）；Check\CheckCheck 没有变化；只有 Whnf\WhnfWhnf，以及经由它的 IsDefEq\IsDefEqIsDefEq，学会了新的 δ 步骤和 ι 步骤。第 12 章展示单个 Whnf\WhnfWhnf 如何处理每一种归纳类型，第 14 章讨论归纳类型给元理论带来的变化。

解释为什么 Eq\Eq{}Eq​ 虽是命题却能消去到每个宇宙，而有两个构造子的类型 Or 却不能。

解答

Eq\Eq{}Eq​ 是子单元：一个构造子，没有字段，所以由其递归子定义的函数无法区分 a=ba = ba=b 的两个证明，因为构造任何这样的证明只有一种方式。Or 有两个构造子，所以它到 Nat\NatNat 的递归子可以对两个注入返回不同的数，使程序的值依赖于提供的是哪个证明。第 8 章精确地给出了这条规则。

要点回顾

  • Eq\Eq{}Eq​ 是归纳族，参数为 AAA 和 aaa，索引为 bbb，只有一个没有字段的构造子 refl\refl{}refl​。
  • 它的递归子沿着 a=ba = ba=b 的证明把关于 aaa 的事实传输为关于 bbb 的事实，而在 refl\refl{}refl​ 上什么也不做。这就是重写。
  • 定义相等由计算判定；命题相等是一个类型，其证明可能需要归纳。refl\refl{}refl​ 把前者变成后者。
  • n+0=nn + 0 = nn+0=n 是定义相等，0+n=n0 + n = n0+n=n 不是，因为加法对第二个参数递归。

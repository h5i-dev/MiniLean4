第 3 章

型付け規則

「項 ttt は型 AAA を持つ」という判断は、項の種類ごとに用意された規則と、型の中で計算してよいとする規則によって決まります。これらの規則を下から上へ読むと、第 5 章で実装する検査の手順が見えてきます。

文脈と判断

f  pf\;pfp のような項は、それだけを見ても検査できません。型は fff と ppp が何であるかによって決まるからです。その情報を記録するのが文脈（context）Γ\GammaΓ です。文脈は仮定の順序付きリスト

Γ  =  x1:A1,  x2:A2,  …,  xn:An,\Gamma \;=\; x_1 : A_1,\; x_2 : A_2,\; \ldots,\; x_n : A_n,Γ=x1​:A1​,x2​:A2​,…,xn​:An​,

で、スコープ内の各変数の型を与えます。dom(Γ)\dom(\Gamma)dom(Γ) は名前の集合 {x1,…,xn}\{x_1, \ldots, x_n\}{x1​,…,xn​} を表し、空の文脈は ⋅\cdot⋅ と書きます。

順序には意味があり、P:Sort 0,  h:PP : \Sort{0},\; h : PP:Sort0,h:P のように、後ろの型が前の変数に言及してもかまいません。仮定 h:Ph : Ph:P は、PPP が命題だとわかってはじめて意味を持ちます。文脈の中の名前は互いに異なるものとするので、文脈は名前から型を引く辞書のように使えます。ただし、項目どうしが前から順に依存し合う辞書です。

二つの判断を同時に定義します。

  • ⊢Γ;ok\ctxok{\Gamma}⊢Γ;ok は、文脈 Γ\GammaΓ が整形式（well formed）であること、つまり仮定した各型がそれより手前の文脈で型になっていることを表します。
  • Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A は、Γ\GammaΓ の仮定のもとで項 ttt が型 AAA を持つことを表します。

Curry-Howard の見方では、Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A は「ttt は仮定 Γ\GammaΓ から AAA を導く証明である」と読めます。

規則のうち二つは項に対する操作を使っていますが、続く数章ではその中身には立ち入らず、ブラックボックスとして扱います。

代入。 T-App に出てくる B[x↦a]\subst{B}{x}{a}B[x↦a] は、BBB の中の xxx の自由な出現をすべて aaa で置き換えた結果を表します。たとえば (P→P)[P↦Q]=Q→Q\subst{(P \to P)}{P}{Q} = Q \to Q(P→P)[P↦Q]=Q→Q です。束縛子の内側で名前を置き換えるときには注意が必要で、その点は第 11 章で説明しますが、それまでは直観的な理解で十分です。

定義的等価。 T-Conv に出てくる A≡BA \conv BA≡B は、AAA と BBB が、カーネルが機械的に判定できる意味で「同じ型」であることを表します。この判定では、次の二種類の違いを無視します。

  • 束縛変数の名前。Π(P:Sort 0). P→P\tPi{P}{\Sort{0}}{P \to P}Π(P:Sort0).P→P と Π(Q:Sort 0). Q→Q\tPi{Q}{\Sort{0}}{Q \to Q}Π(Q:Sort0).Q→Q は同じ命題です。名前だけが異なる項を α 同値であるといい、A=αBA \alphaeq BA=α​B と書きます。
  • 計算。Id=λ(X:Sort 0). X\mathit{Id} = \tLam{X}{\Sort{0}}{X}Id=λ(X:Sort0).X とすると、Id  P\mathit{Id}\;PIdP は XXX に PPP を代入して PPP に計算されるので、Id  P\mathit{Id}\;PIdP の証明は PPP の証明として扱えるべきです。この計算の一歩 (λ(x:A). t)  s→βt[x↦s](\tLam{x}{A}{t})\;s \betared \subst{t}{x}{s}(λ(x:A).t)s→β​t[x↦s] を β 簡約（beta-reduction）と呼びます。

カーネルは、両辺をできるかぎり計算してから結果が α 同値かどうかを調べることで、A≡BA \conv BA≡B を判定します。正確な定義は第 12 章で与えます。

規則の読み方

規則は下から上へ、「結論を得たければ、まず前提を示せ」という手順として読むとわかりやすくなります。

C-Empty と C-Ext。 文脈は仮定を一つずつ加えて作ります。新しく加える仮定の型は、それ自体が型でなければなりません。側条件 x∉dom(Γ)x \notin \dom(\Gamma)x∈/dom(Γ) は同じ名前の仮定が二つ並ぶことを禁じていますが、束縛変数の名前に意味はないので、実質的な制限にはなりません。衝突しそうな束縛子は、先に名前を付け替えれば済みます。この条件を省いたカーネルで何が起きるかは第 11 章で示します。

T-Sort。 どの宇宙も一つ上の宇宙に住みます。Sort 0:Sort 1\Sort{0} : \Sort{1}Sort0:Sort1、Sort 1:Sort 2\Sort{1} : \Sort{2}Sort1:Sort2、以下同様です。宇宙が自分自身の型になれない理由は第 13 章で説明します。

T-Var。 変数は文脈が割り当てた型を持ちます。論理的には、仮定を使うことにあたります。

T-Pi。 AAA が型で、x:Ax : Ax:A を仮定したもとで BBB が型なら、Π(x:A). B\tPi{x}{A}{B}Π(x:A).B も型です。結果の宇宙は imax(u,v)\imax(u, v)imax(u,v) で、v=0v = 0v=0 なら 000、そうでなければ max⁡(u,v)\max(u, v)max(u,v) になります。言い換えると、Π\PiΠ 型は本体が命題でありさえすれば、何について量化していても命題になり、そうでなければ二つの宇宙のうち大きい方に住みます。論理的には、この規則は A→BA \to BA→B や ∀x:A. B\forall x{:}A.\,B∀x:A.B がどんなときに整形式の主張になるかを定めています。

T-Lam。 AAA から BBB への関数を作るには、x:Ax : Ax:A を仮定して型 BBB の項 ttt を作ります。本体の型 BBB は xxx に言及してよく、その言及は結果の Π\PiΠ 型にそのまま残ります。依存性が入り込むのはここです。論理的には含意と全称量化子の導入規則にあたり、A→BA \to BA→B を証明するには AAA を仮定して BBB を証明すればよい、ということを表しています。

T-App。 fff が各 x:Ax : Ax:A を BBB の要素に写し、a:Aa : Aa:A であれば、f  af\;afa は BBB の xxx を aaa で置き換えた型を持ちます。BBB が xxx に言及しない場合は、A→BA \to BA→B と AAA から BBB を導くモーダスポネンスに、言及する場合は全称命題の具体化にあたります。たとえば f:Π(n:Nat). n+0=nf : \tPi{n}{\Nat}{n + 0 = n}f:Π(n:Nat).n+0=n なら f  3:3+0=3f\;3 : 3 + 0 = 3f3:3+0=3 です（自然数は第 7 章で登場します）。

T-Conv。 計算を除いて等しい型は入れ替えてよく、h:Id  Ph : \mathit{Id}\;Ph:IdP から h:Ph : Ph:P を結論できます。前提 Γ⊢B:Sort u\Gamma \vdash B : \Sort{u}Γ⊢B:Sortu は、置き換え先の型もきちんと型であることを保証します。T-Conv は、使うかどうかが ttt の形からは決まらない唯一の規則で、この事実は第 5 章のアルゴリズムで効いてきます。

どの規則も、関数についての小さな常識を述べているにすぎません。T-Lam は関数の作り方、T-App は使い方、T-Pi は関数型がどんなときに意味を持つか、T-Var と T-Sort は基本となるものが何か、T-Conv は型の中で計算しても意味が変わらないことを言っています。規則そのものにとりたてて「論理的」なものはありません。論理は、規則を Curry-Howard の見方で読んだ結果として現れるもので、その対応は第 4 章で正確に述べます。

適用が重要な理由

何かを組み立てる T-Lam や T-Pi のほうが重要に見えるかもしれません。しかし T-App がなければ、証明は仮定を返せても、仮定を使うことはできません。おおまかに言えば、証明できるのは P→Q→PP \to Q \to PP→Q→P のように、結論が仮定の一つそのものである命題だけになってしまいます。合成

(P→Q)→(Q→R)→P→R,(P \to Q) \to (Q \to R) \to P \to R,(P→Q)→(Q→R)→P→R,

の証明は λ(f:P→Q). λ(g:Q→R). λ(p:P). g (f p)\tLam{f}{P \to Q}{\tLam{g}{Q \to R}{\tLam{p}{P}{g\,(f\,p)}}}λ(f:P→Q).λ(g:Q→R).λ(p:P).g(fp) で、fff を適用してから ggg を適用します。仮定を言い直す以上のことをする証明は、必ず T-App を通ります。さらに依存型理論では、T-App は代入が起きる場所でもあり、微妙な問題の大半はここに潜んでいます。

演習

次の各判断を下から上へ処理するとき、使われるのはどの規則で、どんな前提が生じるでしょうか。(a) Γ⊢λ(x:A). x:A→A\Gamma \vdash \tLam{x}{A}{x} : A \to AΓ⊢λ(x:A).x:A→A。(b) Γ⊢Sort 2:Sort 3\Gamma \vdash \Sort{2} : \Sort{3}Γ⊢Sort2:Sort3。(c) f:A→Bf : A \to Bf:A→B のときの Γ⊢f  a:B\Gamma \vdash f\;a : BΓ⊢fa:B。

解答

(a) T-Lam です。前提は、ある uuu についての Γ⊢A:Sort u\Gamma \vdash A : \Sort{u}Γ⊢A:Sortu と、Γ,x:A⊢x:A\Gamma, x : A \vdash x : AΓ,x:A⊢x:A で、後者は T-Var で示せます。結果の型は Π(x:A). A\tPi{x}{A}{A}Π(x:A).A で、束縛子の名前を除けば A→AA \to AA→A と同じです。 (b) T-Sort です。前提は ⊢Γ;ok\ctxok{\Gamma}⊢Γ;ok だけです。 (c) T-App です。前提は Γ⊢f:Π(_:A). B\Gamma \vdash f : \tPi{\_}{A}{B}Γ⊢f:Π(_:A).B と Γ⊢a:A\Gamma \vdash a : AΓ⊢a:A で、_ は BBB に現れないので、結論は B[_↦a]=B\subst{B}{\_}{a} = BB[_↦a]=B になります。

T-Pi を使って、Π(P:Sort 0). P→P\tPi{P}{\Sort{0}}{P \to P}Π(P:Sort0).P→P と Π(A:Sort 1). A→A\tPi{A}{\Sort{1}}{A \to A}Π(A:Sort1).A→A の宇宙を計算してください。

解答

前者では、Sort 0:Sort 1\Sort{0} : \Sort{1}Sort0:Sort1 なので u=1u = 1u=1、P→P:Sort 0P \to P : \Sort{0}P→P:Sort0（再び T-Pi により、u=v=0u = v = 0u=v=0）なので v=0v = 0v=0 です。よって宇宙は Sort imax(1,0)=Sort 0\Sort{\imax(1, 0)} = \Sort{0}Sortimax(1,0)=Sort0 となり、すべての命題について量化する主張も、それ自体が命題になります。 後者では u=2u = 2u=2、A→A:Sort 1A \to A : \Sort{1}A→A:Sort1 なので v=1v = 1v=1 となり、Sort imax(2,1)=Sort 2\Sort{\imax(2,1)} = \Sort{2}Sortimax(2,1)=Sort2 が得られます。この非対称性の理由は第 13 章で説明します。

覚えておくこと

  • 文脈は、名前の重ならない仮定 x:Ax : Ax:A の順序付きリストです。判断 Γ⊢t:A\Gamma \vdash t : AΓ⊢t:A は、その仮定のもとで ttt が型 AAA を持つことを表します。
  • 規則は、項の種類ごとに一つずつと、計算と束縛変数の付け替えを除いて型を同一視する T-Conv からなります。
  • T-App は仮定を使う場所であり、代入が起きる場所でもあります。一方 T-Conv は、項の形によらずに適用される唯一の規則です。
  • 代入と定義的等価は第 III 部までブラックボックスとして扱います。

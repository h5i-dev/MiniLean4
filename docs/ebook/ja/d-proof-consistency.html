付録 D

整合性の証明

第 14 章 は、コア体系が整合的であること、すなわち型 Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P をもつ閉じた項が存在しないことを述べている（定理 14.5）。この付録ではその完全な証明を、議論が使う型付けと変換についての標準的な事実も含めて与える。対象はコア体系、つまり図 3.1 の規則に 第 13 章 の宇宙を加えたもので、第 II 部の定数は含まない。

考え方

証明は、深い定理と初等的な議論を組み合わせる。深い定理とは強正規化である。正しく型付けされた項はすべて正規形に簡約される。これを型保存性と合わせると、型 Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P をもつ閉じた項があるなら、正規な閉じた項にもその型をもつものがあることになる。初等的な議論とは、その型をもつ正規な閉じた項が存在しないことを示す場合分けである。

場合分けは 2 段階で進む。第一に、正規形は λ\lambdaλ でなければならない。閉じていて正規なもののうち、Π\PiΠ 型をもてるのはそれ以外にないからである。第二に、その本体は文脈 P:Sort 0P : \Sort{0}P:Sort0 のもとで型 PPP をもつ項でなければならないが、正規項にそのようなものはない。スコープ内の唯一の変数の型が Sort 0\Sort{0}Sort0 であり、これは PPP でも関数型でもないからである。

場合分けを厳密にするには、各形の項の型がどう見えるか（生成補題）と、形の異なる項が決して変換可能でないこと（合流性の帰結）を知っておく必要がある。まずそれらの事実をまとめる。

型システムについての事実

第 14 章の型保存性と強正規化に加えて、証明は純粋型システム（Pure Type Systems）の次の標準的な性質を使う [Barendregt 1992]。型保存性は、ステップ数についての帰納法により、1 ステップから任意のステップ数へ拡張される。

補題 D.1（標準的な性質）.

(a) 生成（generation）. Γ⊢t:T\Gamma \vdash t : TΓ⊢t:T ならば、ttt の形に応じて次が成り立つ。

  • t=xt = xt=x ならば、ある AAA について (x:A)∈Γ(x : A) \in \Gamma(x:A)∈Γ かつ T≡AT \conv AT≡A。
  • t=Sort ut = \Sort{u}t=Sortu ならば、T≡Sort (u+1)T \conv \Sort{(u+1)}T≡Sort(u+1)。
  • t=Π(x:A). Bt = \tPi{x}{A}{B}t=Π(x:A).B ならば、ある www について T≡Sort wT \conv \Sort{w}T≡Sortw。
  • t=λ(x:A). st = \tLam{x}{A}{s}t=λ(x:A).s ならば、ある BBB について Γ,x:A⊢s:B\Gamma, x : A \vdash s : BΓ,x:A⊢s:B かつ T≡Π(x:A). BT \conv \tPi{x}{A}{B}T≡Π(x:A).B。
  • t=f  at = f\;at=fa ならば、ある xxx、AAA、BBB について Γ⊢f:Π(x:A). B\Gamma \vdash f : \tPi{x}{A}{B}Γ⊢f:Π(x:A).B かつ Γ⊢a:A\Gamma \vdash a : AΓ⊢a:A。

(b) 合流性. s≡ts \conv ts≡t ならば、sss と ttt は共通の項に簡約される。したがって、Π(x:A). B≡Π(y:A′). B′\tPi{x}{A}{B} \conv \tPi{y}{A'}{B'}Π(x:A).B≡Π(y:A′).B′ ならば、新鮮な zzz について A≡A′A \conv A'A≡A′ かつ B[x↦z]≡B′[y↦z]\subst{B}{x}{z} \conv \subst{B'}{y}{z}B[x↦z]≡B′[y↦z] である。また、変数、宇宙、Π\PiΠ のうちどの二つも互いに変換可能でない。

(c) 代入. s≡ts \conv ts≡t ならば、s[z↦a]≡t[z↦a]\subst{s}{z}{a} \conv \subst{t}{z}{a}s[z↦a]≡t[z↦a]。

生成補題とは、型付け規則を逆向きに読んだものである。ある形の項に型を付ける方法は、その形に対応する規則、場合によってはその後に T-Conv を何回か使うものに限られると言っている。各場合が「T=…T = \ldotsT=…」ではなく「T≡…T \conv \ldotsT≡…」となっているのはそのためである。

(b) の帰結が成り立つ理由は次のとおりである。変数と宇宙はまったく簡約されず、Π\PiΠ は Π\PiΠ にしか簡約されない（簡約が起きるのは注釈や本体の内部であって、根では決して起きない）。したがって共通の簡約先をもつ二つの項は、最も外側の形が同じでなければならない。

正規項の形

第 12 章 で見たように、すべての項は背骨 h  a1⋯anh\;a_1 \cdots a_nha1​⋯an​ であり、その頭部 hhh は適用ではない。次の補題は正規項を頭部によって分類する。その役割は、本証明において正規形の可能性を四つだけに絞ることにある。あとはそれぞれを排除すればよい。

補題 D.2（正規形）. nnn を Γ⊢n:T\Gamma \vdash n : TΓ⊢n:T なる正規項とする。このとき nnn は、宇宙、Π\PiΠ、λ\lambdaλ、または頭部 xxx が dom(Γ)\dom(\Gamma)dom(Γ) の変数であるような中立（neutral）項 x  a1⋯akx\;a_1 \cdots a_kxa1​⋯ak​（k≥0k \ge 0k≥0）のいずれかである。さらに k≥1k \ge 1k≥1 ならば、Π\PiΠ に変換可能なある CCC について Γ⊢x:C\Gamma \vdash x : CΓ⊢x:C が成り立つ。

hhh を適用でない項として n=h  a1⋯akn = h\;a_1 \cdots a_kn=ha1​⋯ak​ と書く。

k=0k = 0k=0 ならば n=hn = hn=h は宇宙、Π\PiΠ、λ\lambdaλ、変数のいずれかである。適用以外の形はこれしかないからである。変数は生成補題により dom(Γ)\dom(\Gamma)dom(Γ) に属する。

k≥1k \ge 1k≥1 とする。適用についての生成補題を外側から内側へ kkk 回適用すると、すべての接頭辞 h  a1⋯aih\;a_1 \cdots a_iha1​⋯ai​ が型付け可能であり、特に最も内側の適用 h  a1h\;a_1ha1​ から、ある yyy、AAA、BBB について Γ⊢h:Π(y:A). B\Gamma \vdash h : \tPi{y}{A}{B}Γ⊢h:Π(y:A).B がわかる。ここで hhh の形を考える。まず λ\lambdaλ ではない。そうなら h  a1h\;a_1ha1​ が正規項 nnn の内部の β\betaβ 簡約基になってしまう。宇宙や Π\PiΠ でもない。生成補題によりその型は宇宙に変換可能になるが、合流性により宇宙は Π(y:A). B\tPi{y}{A}{B}Π(y:A).B に変換可能でないからである。したがって hhh は変数 xxx であり、生成補題により dom(Γ)\dom(\Gamma)dom(Γ) に属し、Γ⊢x:Π(y:A). B\Gamma \vdash x : \tPi{y}{A}{B}Γ⊢x:Π(y:A).B が成り立つ。これが求める CCC である。

定理 14.5 の証明

定理 14.5（整合性）. ⋅⊢t:Π(P:Sort 0). P\cdot \vdash t : \tPi{P}{\Sort{0}}{P}⋅⊢t:Π(P:Sort0).P なる閉じた項 ttt は存在しない。

⋅⊢t:Π(P:Sort 0). P\cdot \vdash t : \tPi{P}{\Sort{0}}{P}⋅⊢t:Π(P:Sort0).P と仮定する。強正規化により ttt は正規項 nnn に簡約され、型保存性により ⋅⊢n:Π(P:Sort 0). P\cdot \vdash n : \tPi{P}{\Sort{0}}{P}⋅⊢n:Π(P:Sort0).P である。補題 D.2 を 2 回使って、そのような nnn が存在しないことを示す。

正規形は λ\lambdaλ である。 補題 D.2 により、nnn は宇宙、Π\PiΠ、λ\lambdaλ、中立項のいずれかである。

  • 中立項ではない。頭部が空の文脈の変数になるはずだが、そのような変数はない。
  • 宇宙や Π\PiΠ でもない。生成補題により Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P が宇宙に変換可能になるが、合流性がそれを排除する。

よって n=λ(x:A). sn = \tLam{x}{A}{s}n=λ(x:A).s である。生成補題により、ある BBB について x:A⊢s:Bx : A \vdash s : Bx:A⊢s:B かつ Π(P:Sort 0). P≡Π(x:A). B\tPi{P}{\Sort{0}}{P} \conv \tPi{x}{A}{B}Π(P:Sort0).P≡Π(x:A).B である。合流性により、新鮮な zzz について A≡Sort 0A \conv \Sort{0}A≡Sort0 かつ P[P↦z]≡B[x↦z]\subst{P}{P}{z} \conv \subst{B}{x}{z}P[P↦z]≡B[x↦z]、すなわち z≡B[x↦z]z \conv \subst{B}{x}{z}z≡B[x↦z] である。両辺で zzz に xxx を代入すると、補題 D.1 の (c) により変換可能性が保たれるので、x≡Bx \conv Bx≡B を得る。本体 sss は正規項 nnn の部分項なので正規である。まとめると、A≡Sort 0A \conv \Sort{0}A≡Sort0 かつ B≡xB \conv xB≡x のもとで x:A⊢s:Bx : A \vdash s : Bx:A⊢s:B である。

本体は存在しえない。 Γ=x:A\Gamma = x : AΓ=x:A とおく。補題 D.2 により、sss は宇宙、Π\PiΠ、λ\lambdaλ、中立項のいずれかである。

  • sss が宇宙または Π\PiΠ なら、生成補題により BBB は宇宙に変換可能になる。sss が λ\lambdaλ なら、BBB は Π\PiΠ に変換可能になる。しかし B≡xB \conv xB≡x であり、合流性により変数はどちらにも変換可能でない。
  • sss が中立項なら、その頭部は dom(Γ)={x}\dom(\Gamma) = \{x\}dom(Γ)={x} の変数なので s=x  a1⋯aks = x\;a_1 \cdots a_ks=xa1​⋯ak​ である。k=0k = 0k=0 なら s=xs = xs=x で、生成補題により B≡AB \conv AB≡A。すると x≡B≡A≡Sort 0x \conv B \conv A \conv \Sort{0}x≡B≡A≡Sort0 となるが、変数は宇宙に変換可能でない。k≥1k \ge 1k≥1 なら、補題 D.2 により Π\PiΠ に変換可能な CCC について Γ⊢x:C\Gamma \vdash x : CΓ⊢x:C であり、変数 xxx についての生成補題により C≡A≡Sort 0C \conv A \conv \Sort{0}C≡A≡Sort0。すると Π\PiΠ が宇宙に変換可能になり、合流性がそれを排除する。

すべての場合が矛盾に至るので、型 Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P をもつ閉じた項は存在しない。

言葉で言えばこうである。λ\lambdaλ の内側で使える変数は xxx だけで、その型は Sort 0\Sort{0}Sort0 である。Sort 0\Sort{0}Sort0 は xxx ではないのでそのまま返すことはできず、Sort 0\Sort{0}Sort0 は関数型ではないので何かに適用することもできない。それ以外の正規項はすべて宇宙か Π\PiΠ を型にもつが、xxx はどちらでもない。この議論は、問題を正規項に帰着させるために強正規化に頼っている。難しさはすべてそのステップにある。

証明の後半、正規項の分析は、強正規化を使わず、宇宙の構造にも依存しない。Type:Type\mathsf{Type} : \mathsf{Type}Type:Type をもつ体系にもそのまま移る。第 13 章が、その体系で型 Π(P:Type). P\tPi{P}{\mathsf{Type}}{P}Π(P:Type).P をもつ Hurkens の項（付録 C）には正規形がありえないと結論するのはこのためである。正規形があれば、この分析がそれを排除してしまう。つまり整合的でない体系で破れるのは強正規化であって、生成補題や合流性ではない。

第 II 部の帰納型を加えると、正規形には nnn が変数であるような Nat.recu  M  z  s  n\NatRec{u}\;M\;z\;s\;nNat.recu​Mzsn のように行き詰まった再帰子の適用も含まれるようになり、上の短い場合分けだけでは足りなくなる。拡張した体系はその断片にあたる帰納的構成の計算（Calculus of Inductive Constructions）の整合性は、正規形をより丁寧に分析することで強正規化から導かれる [Werner 1994]。

覚えておくこと

  • 整合性は、強正規化と型保存性（正規形に移るため）を、正規項の形についての場合分けと組み合わせて証明する。
  • 場合分けは二つの標準的な事実を使う。生成補題（型付け規則を逆向きに読んだもの）と合流性（最も外側の形が異なる項は決して変換可能でない）である。
  • 型 Π(P:Sort 0). P\tPi{P}{\Sort{0}}{P}Π(P:Sort0).P をもつ正規な閉じた項は、文脈 x:Sort 0x : \Sort{0}x:Sort0 のもとで本体が型 xxx をもつ λ\lambdaλ でなければならないが、そのような正規項はない。
  • 難しい部分は強正規化である。形の分析だけなら Type:Type\mathsf{Type} : \mathsf{Type}Type:Type にも適用でき、Hurkens の項に正規形がないことを示す。
